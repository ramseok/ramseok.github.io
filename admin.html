관리자 페이지 설정이 필요합니다

config.js 에 Supabase 연결 정보가 비어 있습니다. 아래 순서로 한 번만 설정하면 됩니다.

  1. supabase.com 에서 프로젝트 생성 (Region: Northeast Asia — Seoul)
  2. SQL Editor 에 비공개 저장소의 setup/supabase-setup.sql 내용을 붙여넣고 Run — 테이블·권한·이미지 버킷이 만들어집니다
  3. Authentication → Users → Add user 로 관리자 계정(이메일·비밀번호) 생성. 이메일이 SQL 의 owner_email 과 같아야 합니다
  4. Authentication → Providers → Email 에서 Allow new users to sign up 을 끕니다 (타인 가입 차단)
  5. Project Settings → API 의 Project URL 과 anon public key 를 config.js 에 넣고 push
