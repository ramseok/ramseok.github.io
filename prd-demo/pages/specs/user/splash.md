# P1 스플래시

> URL `/` · 대상 **사용자** · 관련 기능 없음 (전제 화면 — 앱 실행 시 최초 진입점)

앱을 처음 실행했을 때 잠깐 노출되는 브랜드 화면이다. 사용자의 조작 없이 서비스명과 태그라인만 보여주고 일정 시간 후 자동으로 로그인 화면(P2)으로 넘어간다. 헤더·탭바가 없는 유일한 화면으로, 이 뒤로 로그인(P2) → 상태별 홈(P4) 흐름이 이어진다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 상태바 | 9:41 시계, 신호·와이파이·배터리 아이콘 (디자인 목업용 고정 표시) | - |
| 스플래시 마크 | 원형 배경 안에 강아지 아이콘 | - |
| 서비스명 | "무지개 일기" + 옆에 작은 글씨로 "(가칭)" 캡션 | - |
| 태그라인 | "오늘도, 이별 후에도 곁에 있어요" 2줄 문구, 서비스명 아래 회색 톤으로 표시 | - |
| 하단 로딩 인디케이터 | 화면 하단에 점 3개가 순서대로 깜빡이는 애니메이션 | - |

## 동작 정의

### 1. 화면 진입과 표시

1. 화면 진입 시 헤더·탭바 없이 상태바와 스플래시 콘텐츠(마크·서비스명·태그라인·로딩 점)만 표시된다.
2. localStorage에 저장된 글자 크기 설정(`rd-font-scale`)이 `lg` 또는 `xl`이면 화면 전체에 해당 확대 크기가 적용된 채로 표시된다(F8의 접근성 표시 옵션이 다른 화면과 동일하게 스플래시에도 반영됨).

### 2. 자동 전환

1. 화면 진입 후 사용자 조작 없이 1.8초가 지나면 자동으로 로그인 화면(P2, `login.html`)으로 이동한다.
2. 시안에는 버튼이나 스킵 동작이 없다 — 전환은 타이머로만 발생한다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 전환 타이머 진행 중 사용자가 화면을 탭/스와이프함 | 시안에는 별도 반응 없음 — 어떤 조작도 화면 전환에 영향을 주지 않는다 |
| 이미 로그인된 상태로 앱을 재실행함 | 시안에서는 세션 여부와 무관하게 항상 로그인(P2)으로 이동한다 — 개발 반영 시 세션이 있으면 홈(P4)으로 바로 보내는 분기가 필요 |
| 네트워크 지연·리소스 로딩 실패 | 시안에는 대체 화면·에러 처리 없음 — 타이머는 네트워크 상태와 무관하게 항상 1.8초 후 실행됨 |

## 확정 필요

- 02_PAGE.md 계약상 스플래시의 다음 화면은 P2(로그인)와 P4(홈) 둘 다로 정의되어 있으나, 현재 시안은 세션 분기 없이 항상 P2로만 이동한다. 실제 서비스에서 로그인 세션 유지 시 P4로 바로 보낼지 확정 필요
- 전환 대기시간 1.8초가 최종값인지, 로딩 리소스(폰트·아이콘 등) 준비 완료를 기다리는 로직이 필요한지 확정 필요
