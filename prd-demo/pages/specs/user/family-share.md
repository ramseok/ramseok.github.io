# P7 가족 공유

> URL `/mypage/family` · 대상 **사용자** · 관련 기능 F7

반려견별로 공동 보호자를 초대하고 편집/보기 권한을 관리하는 화면이다. 상단에는 외부 초대 링크로 들어온 사용자를 위한 수락 배너가 있고, 이어서 현재 보고 있는 반려견의 가족 구성원 목록, 하단 고정 CTA로 새 가족을 초대하는 흐름이 이어진다. 상단 전환 버튼으로 다른 반려견(보리/콩이)의 가족 구성원 목록으로 바꿔볼 수 있다.

## 동작 정의

### 1. 초대 수락 배너 (F7)

1. 화면에 진입하면 상단에 초대 수락 배너가 항상 노출된다(시안은 대기 중 초대가 있다고 가정한 고정 상태).
2. "수락할게요"를 누르면 배너 문구가 "OO의 가족이 됐어요. 언제든 OO의 소식을 함께 볼 수 있어요."로 바뀌고 토스트가 뜬다. 버튼은 함께 사라진다.
3. "나중에요"를 누르면 배너 섹션 전체가 화면에서 사라지고 "초대를 미뤄뒀어요" 토스트가 뜬다.
4. 개발 반영 시 대기 중 초대가 없는 사용자는 배너 자체를 숨겨야 한다(시안은 조건 없이 고정 노출).

### 2. 반려견 전환 (F7)

1. 상단 "OO의 가족" 버튼을 누르면 반려견 선택 바텀시트가 열리고 보리·콩이 목록이 뜬다.
2. 목록에서 반려견을 고르면 해당 반려견의 "OO의 가족" 라벨로 갱신되고, 그 반려견의 가족 구성원 섹션으로 화면이 전환되며, 시트가 닫히고 토스트가 뜬다.
3. 시안은 보리(가족 4명)·콩이(가족 2명) 두 반려견 데이터만 고정으로 가진다.

### 3. 가족 구성원 목록 확인 (F7)

1. 소유자(나)는 항상 목록 첫 줄에 고정 표시되며 권한 변경·해제 메뉴가 없다.
2. 구성원별로 이름·관계 문구와 권한 태그(편집 권한/보기 권한)가 표시된다.
3. 수락 대기 중인 구성원은 권한 태그 대신 "수락 대기" 상태 태그와 초대일·예정 권한 문구가 표시된다.
4. 구성원 행의 더보기 버튼을 누르면 해당 구성원의 관리 바텀시트가 열린다.

### 4. 구성원 권한 변경·해제 (F7)

1. 관리 바텀시트 제목은 수락 완료 구성원은 "OO님의 권한", 대기 중 구성원은 "OO님 초대 관리"로 다르게 표시된다.
2. 편집 권한/보기 권한 중 하나를 선택하면 목록의 권한 태그가 즉시 바뀌고 "OO님의 권한을 OO 권한으로 바꿨어요" 토스트가 뜬다. 대기 중 구성원은 메타 문구의 예정 권한 표기도 함께 바뀐다.
3. 수락 대기 구성원에게만 "초대 다시 보내기" 버튼이 노출되며, 누르면 시트가 닫히고 "다시 보냈어요" 토스트가 뜬다.
4. 하단 버튼 라벨은 수락 완료 구성원은 "가족에서 내보내기", 대기 중 구성원은 "초대 취소"로 바뀐다. 누르면 목록에서 해당 행이 즉시 삭제되고 각각 다른 문구의 토스트가 뜬다.

### 5. 새 가족 초대하기 (F7)

1. 하단 고정 CTA를 누르면 초대 바텀시트가 열리고 현재 보고 있는 반려견 이름이 타이틀에 표시된다.
2. "연락처 또는 이메일" 입력칸(placeholder "010-0000-0000 또는 이메일")과 권한 선택 세그먼트(편집 권한이 기본 선택)가 있다.
3. 입력칸이 비어 있으면 "초대 보내기"를 눌러도 진행되지 않고 입력칸에 포커스만 이동한다(형식 유효성 검사 없음).
4. 값을 입력하고 "초대 보내기"를 누르면 현재 반려견의 구성원 목록 맨 아래에 "수락 대기" 상태의 새 행이 즉시 추가되고, 시트가 닫히며 토스트가 뜬다. 화면 내 임시 반영이라 새로고침하면 사라진다(개발 반영 시 서버 저장 필요).
5. "초대 링크 복사하기"를 누르면 실제 클립보드 동작 없이 "복사됐어요" 토스트만 뜬다(시안 한정).

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 대기 중인 초대가 없는 사용자 | 시안은 배너를 항상 노출(개발 반영 시 조건부 숨김 필요) |
| 반려견이 1마리뿐인 계정 | 시안은 보리·콩이 2마리 고정, 반려견 1마리일 때 전환 버튼 노출 여부 미정 |
| 초대 입력값 형식 오류(잘못된 연락처/이메일) | 시안에 별도 유효성 검사·에러 메시지 없음 |
| 새로고침·재진입 | 추가·삭제한 구성원 행은 저장되지 않고 초기 데이터로 복귀 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 초대 수락 배너의 예시 반려견명("초코")이 실제 반려견 목록(보리·콩이)에 없음 — 개발 반영 시 실제 대기 초대 데이터 연동 방식 확인 필요
- 연락처/이메일 입력 형식 유효성 검사 규칙
- 반려견이 1마리도 없거나 가족 구성원이 0명일 때의 빈 상태 문구
- 소유자 권한 이전(공동 소유자 지정) 지원 여부
