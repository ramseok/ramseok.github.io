# P18 메모리얼 페이지 관리

> URL `/memorial/edit` · 대상 **사용자** · 관련 기능 F23, F24, F26, F35, F37

무지개다리 전환 시 자동 생성된 반려견의 추모관(메모리얼 페이지)을 보호자가 꾸미고 공개 범위를 정하는 관리 화면이다. 대표 사진·배경 테마·노출 섹션 순서를 편집하고, 공개 범위와 공유 링크를 관리하며, 방명록을 관리한다. 하단에서 하늘로 보내는 편지(P20)·추억 앨범·회고록(P23)으로 이어진다. 무지개다리 홈(P4) 또는 전환 직후(P6)에서 진입한다.

## 동작 정의

### 1. 추모관 미리보기 (F23, F35)

1. 진입 시 자동 생성된 추모관 미리보기 카드에 이름·함께한 기간(입양일~이별일)·한마디가 표시된다.
2. 헤더의 눈 아이콘 또는 카드의 "방문자 화면 보기" 버튼을 누르면 공개 추모관(P19)이 새 탭에서 열린다.
3. 시안에서는 "방명록 새 글 2개" 배지가 고정 값으로 표시된다(개발 반영 시 실제 미확인 글 수로 대체).

### 2. 대표 사진·배경 테마 (F23)

1. "변경" 버튼을 누르면 파일 선택창이 열리고, 이미지를 고르면 대표 사진 메타 문구가 "오늘 새로 설정함"으로 바뀌고 토스트가 뜬다(시안은 실제 업로드 없이 문구만 갱신).
2. "사진 선택" 버튼으로 이미지를 여러 장 고르면 대표 추억 사진 메타 문구가 선택 장수로 갱신되고 토스트가 뜬다.
3. 잠금 없는 테마(크림 담요, 새벽 하늘) 중 하나를 누르면 즉시 활성 표시(체크)가 옮겨가고 토스트가 뜬다.
4. 잠금 표시된 테마(벚꽃 잎, 별이 총총)를 누르면 "프리미엄에서 이용할 수 있는 테마예요" 토스트만 뜨고 선택은 바뀌지 않는다.

### 3. 노출 섹션 순서 (F23)

1. 한마디·추억 타임라인·편지·녹음·방명록 순서로 목록이 나오고, 켜둔 섹션만 이 순서 그대로 방문자 화면(P19)에 노출된다(목록 위 안내 "켜둔 섹션만, 이 순서 그대로 방문자 화면에 보여요.").
2. 각 항목의 토글을 끄면 항목이 흐려지고 상태 문구가 "숨김"으로, 켜면 "노출 중"으로 바뀐다.
3. 위/아래 화살표로 순서를 바꿀 수 있으며, 맨 위 항목은 위 화살표가, 맨 아래 항목은 아래 화살표가 비활성화된다.

### 4. 공개 범위·공유 링크 (F24, F37)

1. 비공개/가족 공유/링크 공개 중 하나를 고르면 라디오가 즉시 바뀌고, 미리보기 카드의 공개 범위 태그도 같이 갱신되며, 토스트 "공개 범위를 "OO"(으)로 바꿨어요"가 뜬다.
2. "링크 공개"를 선택했을 때만 공유 링크 박스와 재발급 버튼이 보이고, 다른 범위에서는 숨겨진다.
3. "복사" 버튼을 누르면 공유 링크 값이 클립보드에 복사되고 토스트가 뜬다.
4. "재발급" 버튼을 누르면 확인 모달이 뜨며, 기존 링크가 즉시 무효화된다는 경고 문구가 표시된다. "재발급할게요"를 누르면 새 토큰으로 링크 값이 바뀌고 토스트가 뜨며, "취소"를 누르면 모달만 닫히고 값은 유지된다.
5. 하단에 "검색엔진에 노출되지 않아요" 안내 문구가 항상 표시된다.
6. 시안의 기본 공개 범위는 "링크 공개" 상태로 고정되어 있다. 실서비스에서 추모관을 최초 생성할 때 기본값은 "비공개"이며, 시연 편의를 위해 이미 링크가 발급된 상태로 보여주는 것이다.

### 5. 방명록 관리 (F26)

1. "비회원 작성 허용" 토글을 끄면 안내 문구가 "가족 구성원만 글을 남길 수 있어요"로 바뀌고 토스트가 뜬다.
2. 방명록 목록은 가족 태그가 붙은 회원 작성자(이모 수진, 언니 은지)와 비회원 작성자를 구분해 보여준다(시안은 더미 7건 고정, 공개 추모관 P19 목록과 작성자·내용·날짜 동일).
3. "숨기기"를 누르면 이름·내용이 흐리게 취소선 처리되고 버튼이 "숨김 해제"로 바뀐다. 다시 누르면 원상 복구된다.
4. "삭제"를 누르면 별도 확인 없이 즉시 애니메이션 후 목록에서 제거된다.

### 6. 더 살펴보기 (연계)

1. "하늘로 보내는 편지" 항목을 누르면 P20(letter-to-sky.html)으로 이동한다. 진입 전 "편지 7통 보관 중" 문구가 표시된다.
2. "추억 앨범 · 회고록" 항목(보조 문구 "사진을 모아 한 권으로 남겨요")을 누르면 P23(memorial-extras.html)으로 이동한다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 공개 범위가 링크 공개가 아닐 때 | 공유 링크 박스·재발급 버튼이 숨겨진다 |
| 재발급 모달에서 취소 | 기존 공유 링크 값이 그대로 유지된다 |
| 프리미엄 테마 클릭 | 안내 토스트만 뜨고 테마는 적용되지 않는다 |
| 방명록 글 전부 삭제 | 목록이 빈 채로 남는다(빈 상태 전용 UI는 시안에 없음) |
| 노출 섹션 전부 숨김 | 방문자 화면에 아무 섹션도 노출되지 않는 상태가 될 수 있다 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 배경 테마 프리미엄 잠금 클릭 시 결제/구독 화면(F38)으로 바로 이동시킬지, 안내 토스트만 유지할지
- 노출 섹션을 전부 숨긴 경우 최소 1개 강제 노출 등 정책이 필요한지
- 방명록 삭제를 확인 모달 없이 즉시 처리할지(시안 기준), 되돌리기를 제공할지
- 미리보기 카드의 "방명록 새 글 N개" 배지의 실제 집계 기준(읽음/안읽음 여부)
