# P10 다이어리 작성·수정 (무지개 일기(가칭))

> URL `/diary/write` · 대상 **사용자** · 관련 기능 F9, F36, F38

일상 다이어리(F9)를 새로 쓰거나 기존 기록을 고치는 화면이다. 목록(P9)에서 "새 다이어리"로 들어오면 빈 작성 폼이, 목록·타임라인(P13)에서 기존 카드를 누르면 `?id=` 파라미터와 함께 들어와 기존 내용이 채워진 수정 폼이 뜬다 — 별도의 읽기 전용 상세 화면 없이 이 화면 하나가 작성·수정·상세 열람을 겸한다. 날짜·사진·영상·기분·본문을 입력한 뒤 저장하면 목록(P9)으로 돌아간다.

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 좌측 닫기(X), 중앙 제목("다이어리 쓰기"/"다이어리 수정"), 수정 모드에서만 우측 "삭제" 버튼 노출 | F9 |

| 영상 | 라벨 "영상 (선택, 1개)", 사진과 같은 크기의 추가 타일 1개, 업로드 시 길이 배지 표시, 타일 아래에 무료/프리미엄 길이 안내 문구 | F9, F36 |

| 토스트 | 하단에 3초간 노출되는 메시지 | - |

## 동작 정의

### 1. 진입·모드 분기 (F9)

1. `?id=` 파라미터 없이 진입하면 제목이 "다이어리 쓰기"로, 날짜는 오늘 날짜로 자동 채워진 빈 폼이 뜬다. 삭제 버튼은 보이지 않는다.
2. `?id=` 파라미터와 함께 진입하면(목록·타임라인에서 기존 기록 선택) 제목이 "다이어리 수정"으로 바뀌고, 삭제 버튼이 나타난다.
3. 수정 모드에서는 시안 더미 데이터로 날짜(2026-09-26), 본문 텍스트, 기분 태그("행복" 선택), 사진 2장이 자동으로 채워져 보여진다. 실제 개발에서는 해당 `id`의 저장된 기록을 불러와 채운다 (개발 반영 시).

### 2. 사진 업로드 (F9, F36, F38)

1. "추가" 타일을 누르면 새 사진 타일이 목록 끝(추가 타일 앞)에 추가되고 카운트가 올라간다.
2. 각 사진 타일 우상단의 삭제 버튼을 누르면 그 타일이 제거되고 카운트가 내려간다.
3. 사진이 10장에 도달하면 추가 버튼이 비활성화(흐리게)되고, "사진은 한 번에 최대 10장까지 담을 수 있어요" 경고 배너가 나타난다. 10장 미만이면 배너는 숨는다.
4. 업로드된 사진은 원본을 별도 보관한다는 안내가 화면 하단에 상시 노출된다 (F36).

### 3. 영상 업로드 (F9, F36, F38)

1. 영상은 최대 1개만 담을 수 있다. "추가" 타일을 누르면 재생시간 배지(시안 더미값 "0:42")가 붙은 영상 타일이 생기고, 추가 버튼은 숨는다.
2. 영상 추가 시 "영상은 무료 회원 1분까지 담을 수 있어요" 토스트가 뜬다. 영상 타일 아래에는 "무료 회원은 최대 1분, 프리미엄 회원은 최대 5분까지 올릴 수 있어요"라는 고정 안내 문구가 있다.
3. 영상 타일의 삭제 버튼을 누르면 타일이 제거되고 추가 버튼이 다시 나타난다.
4. 시안에서는 실제 업로드 파일의 길이를 재지 않고 배지 값이 고정되어 있다 — 실 업로드 시 길이 측정·한도 초과 차단 로직은 개발 반영 시 붙는다.

### 4. 기분 태그·본문 (F9)

1. 기분 칩(행복/평온/아픔/특별한 날) 중 하나를 누르면 해당 타일만 선택 표시(테마 색 배경 + 테두리)되고, 다른 칩을 누르면 선택이 그쪽으로 옮겨간다. 동시에 두 개 이상 선택되지 않는다.
2. 본문 textarea에 입력하는 즉시 라벨 우측의 글자 수 표시가 "n / 1000자"로 갱신된다. 1000자를 넘겨 입력할 수 없다.

### 5. 나가기·저장·삭제 (F9)

1. 헤더의 닫기(X) 버튼 또는 하단 "취소" 버튼을 누르면 입력 내용 저장 없이 다이어리 목록(P9)으로 이동한다.
2. "저장" 버튼을 누르면 "소중한 하루가 저장됐어요" 토스트가 뜨고 약 0.7초 뒤 다이어리 목록(P9)으로 이동한다. 시안에서는 필수 입력값 검증 없이 항상 저장에 성공한다.
3. 수정 모드에서만 보이는 "삭제" 버튼을 누르면 "다이어리를 지웠어요" 토스트가 뜨고 약 0.7초 뒤 다이어리 목록(P9)으로 이동한다. 삭제 확인 절차(재확인 모달 등)는 시안에 없다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 사진 10/10 도달 | 추가 타일 비활성화 + "최대 10장" 경고 배너 노출 |
| 사진 10장 미만 | 경고 배너 숨김, 추가 타일 활성 |
| 영상 이미 1개 있음 | 영상 추가 타일 자체가 숨김 처리되어 더 추가할 수 없다 |
| 수정 모드(`?id=` 있음) | 제목·삭제 버튼·기존 값이 시안 더미 데이터로 채워짐 |
| 저장/삭제 처리 중 | 별도 로딩 표시 없이 토스트 → 0.7초 후 목록으로 즉시 이동 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 타임라인(P13)에서 다이어리 항목을 눌러 이 화면에 들어온 경우, 저장·닫기 후 되돌아갈 곳이 다이어리 목록(P9)이 맞는지, 타임라인으로 돌아가야 하는지
- 저장 시 최소 입력 조건(사진·본문 중 최소 1개 필수 등) 여부
- 삭제 버튼에 확인 모달을 넣을지 여부
- 실제 업로드 사진 용량·형식 제한, 영상 길이 실측 및 한도 초과 시 업로드 차단 처리 (개발 반영 필요)
