# P25 1:1 문의 (무지개 일기(가칭))

> URL `/mypage/inquiry` · 대상 **사용자** · 관련 기능 F33

> **F33은 계약서 외 전제 기능이다.** 관리자 측 응대(F40, ADM-01)와 짝을 이루는 사용자 측 화면으로, 사용자가 문의를 등록하고 상담팀 답변을 확인하는 흐름만 이 화면에서 다룬다.

마이페이지에서 진입해 문의 유형·내용·사진을 등록하고("문의하기" 탭), 등록한 문의의 답변 상태를 확인하는("문의 내역" 탭) 화면이다. 새 문의를 등록하면 목록 맨 위에 "답변대기"로 추가되고 자동으로 내역 탭으로 전환된다.

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기(마이페이지로) + 타이틀 "1:1 문의" | - |
| 탭 | 문의하기 / 문의 내역(건수 뱃지) 2개, 스크롤해도 본문 상단에 고정 | F33 |

| 문의하기 — 문의 내용 | 텍스트 영역(최대 500자, 실시간 글자 수, 필수) | F33 |

| 문의하기 — 개인정보 안내 배너 | "개인정보 안 적어도 괜찮다, 계정 확인은 로그인 정보로 진행" 안내 | F33 |

| 문의 내역 — 요약줄 | 총 건수 · 답변대기 건수 + "새 문의" 버튼 | F33 |
| 문의 내역 — 목록 | 아코디언 카드(유형 태그·상태 태그·제목·날짜, 펼치면 질문 전문 + 답변/대기 안내) | F33 |
| 문의 내역 — 빈 상태 | 문의가 0건일 때 안내 + "문의 남기기" 버튼 | F33 |

## 동작 정의

### 1. 탭 전환 (F33)

1. 화면 진입 시 "문의하기" 탭이 기본 활성 상태다.
2. "문의 내역" 탭을 누르면 문의하기 영역이 숨겨지고 등록된 문의 목록이 표시되며, 탭 옆 뱃지에 총 건수가 괄호로 표시된다.
3. 문의 내역 탭의 "새 문의" 버튼, 빈 상태의 "문의 남기기" 버튼을 누르면 문의하기 탭으로 돌아간다.
4. 탭을 전환할 때마다 본문 스크롤이 맨 위로 초기화된다.
5. 탭 바는 본문을 아래로 스크롤해도 화면 상단(헤더 바로 아래)에 고정되어 계속 보인다.

### 2. 문의 등록 (F33)

1. 문의 유형 칩은 하나만 선택되며, 다시 다른 칩을 누르면 이전 선택이 해제되고 새 칩이 활성 표시된다.
2. 문의 내용을 입력하면 글자 수가 "n / 500자"로 실시간 갱신된다(최대 500자).
3. "추가" 타일을 누르면 첨부 사진 타일이 하나 늘고, 개수 표시가 "n / 3"으로 갱신된다. 3장을 채우면 "추가" 타일이 비활성화된다.
4. 각 첨부 타일 우측 상단의 삭제 버튼을 누르면 해당 타일이 제거되고 개수·"추가" 타일 활성 상태가 다시 갱신된다.
5. 시안에서 첨부 타일은 실제 이미지 업로드 없이 자리표시 아이콘만 채워지는 더미 동작이다.
6. "문의 등록하기"를 누르면 유형·내용을 검증한다. 유형을 선택하지 않았거나 내용이 비어 있으면 해당 항목에 오류 메시지가 표시되고, 어느 항목이 비었든 문의 유형 영역이 화면 가운데 오도록 스크롤 이동하며 등록되지 않는다.
7. 검증을 통과하면 입력한 유형·내용(최대 40자 미리보기)·첨부 장수가 "답변대기" 상태 카드로 문의 내역 목록 맨 위에 추가되고, 날짜는 "9월 29일 (화) · 방금 등록"으로 표시된다.
8. 등록 후 입력 폼(유형 선택·내용·첨부)이 초기화되고, 토스트 "문의가 접수됐어요. 답변은 보통 1~2일 안에 드려요."가 뜬 뒤 약 0.7초 후 자동으로 "문의 내역" 탭으로 전환된다.

### 3. 문의 내역 확인 (F33)

1. 목록 상단에 총 건수와 답변대기 건수가 표시되며, 문의를 등록하거나 목록에 변화가 있을 때마다 즉시 갱신된다.
2. 각 문의 카드는 유형 태그·상태 태그(답변대기/답변완료)·제목·등록일을 보여주고, 카드를 누르면 아코디언이 펼쳐져 질문 전문이 노출된다. 같은 카드를 다시 누르면 접힌다.
3. "답변대기" 문의는 펼쳤을 때 "아직 답변 전이에요. 순서대로 확인 후 답변드릴게요." 안내만 보인다.
4. "답변완료" 문의는 펼쳤을 때 "무지개 일기 상담팀 · 답변일" 표기와 답변 본문이 함께 보인다.
5. 첨부 사진이 있는 문의는 헤더 줄에 "사진 n장" 표시가 함께 붙는다.
6. 시안 더미 데이터는 문의 8건(답변대기 2건, 답변완료 6건)이 고정되어 있다. 답변완료 문의는 등록일 다음 날 전후로 상담팀 답변이 달린 상태로 보인다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 문의 유형 미선택 후 등록 시도 | 유형 영역에 "문의 유형을 선택해주세요" 오류 노출 + 해당 영역으로 스크롤 |
| 문의 내용 미입력 후 등록 시도 | 내용 영역에 "문의 내용을 입력해주세요" 오류 노출 + 문의 유형 영역으로 스크롤(바로 아래 내용 영역이 함께 보임) |
| 문의 내역 0건 | 카드 목록 대신 빈 상태(안내 문구 + "문의 남기기" 버튼) 노출. 시안 더미 데이터는 8건 고정이라 실제로는 발생하지 않음 |
| 첨부 3장 도달 | "추가" 타일 비활성화, 삭제 시 다시 활성화 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 첨부 사진은 시안에서 실제 파일 선택 없이 더미 아이콘 타일만 추가되는 동작이다. 개발 반영 시 실제 이미지 선택·미리보기·업로드 처리가 필요한지 확인 필요.
- 등록 직후 카드는 클라이언트 메모리에만 추가되며 새로고침하면 사라진다. 개발 반영 시 실제 서버 저장과 새로고침 후 유지 여부 확인 필요.
- 관리자 응대(F40) 완료 시 사용자에게 별도 알림(푸시 등)을 줄지, 이 화면에 재진입해야만 답변을 확인하는 구조로 둘지 확인 필요.
