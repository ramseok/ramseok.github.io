# P20 하늘로 보내는 편지

> URL `/memorial/letters` · 대상 **사용자** · 관련 기능 F27

무지개다리 이후 보호자가 반려견에게 못다 한 말을 편지로 남기고, 날짜별로 모아 보관하며 편지마다 공개 여부를 따로 정하는 화면이다. 공개로 설정한 편지는 추모관(P19) 편지 섹션에도 함께 노출된다. 메모리얼 페이지 관리(P18)에서 진입하며, 탭바 없이 하단 고정 CTA로 작성 동작을 제공한다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 상단 헤더 | 뒤로가기(메모리얼 페이지 관리 P18로 이동) + 타이틀 "하늘로 보내는 편지" | F27 |
| 안내 카드 | 편지 아이콘 + "편지 {n}통 보관 중"(동적 집계) + "보리에게 못다 한 말을 편지로 남겨보세요. 날짜별로 모아두고, 편지마다 공개 여부도 따로 정할 수 있어요." 안내 문구 + "편지 개수에는 제한이 없어요. 따로 알려드리지 않으니 편하실 때 남겨주세요." 캡션 | F27 |
| 공개 범위 필터 칩 | 전체 / 공개 / 비공개 단일 선택, 목록에 즉시 필터 반영 | F27 |

| 편지 쓰기·수정 바텀시트 | 제목("편지 쓰기" / "편지 수정"), 작성일 안내, "보리에게 전하는 말" 입력창(placeholder "편하게, 하고 싶은 말을 적어보세요"), "공개로 남기기" 토글(+ "공개하면 추모관 편지 섹션에도 함께 보여요"), 취소·저장 버튼, (수정 모드만) 그 아래 "이 편지 삭제하기" 버튼 | F27 |
| 토스트 | 공개 전환·저장·삭제 결과를 하단에 짧게 안내 | F27 |

## 동작 정의

### 1. 편지 목록 조회·필터링 (F27)

1. 진입하면 날짜별 그룹으로 묶인 편지 카드가 최신 날짜순으로 표시되고, 안내 카드의 보관 통수는 실제 카드 개수를 세어 표시된다.
2. 필터 칩(전체/공개/비공개)을 선택하면 조건에 맞는 카드만 남고 나머지는 숨겨지며, 소속 카드가 모두 숨겨진 날짜 그룹은 통째로 숨겨진다.
3. 필터 결과가 하나도 없으면 목록 전체 대신 빈 상태 안내("조건에 맞는 편지가 없어요.")가 표시된다.

### 2. 공개·비공개 개별 전환 (F27)

1. 카드 우측 상단의 공개/비공개 태그 버튼을 누르면 카드 클릭(수정 진입)과 별도로 해당 편지만 공개↔비공개로 즉시 전환되고 태그 아이콘·문구가 바뀐다.
2. 공개로 전환하면 "공개로 바뀌었어요. 추모관에도 함께 보여요" 토스트가, 비공개로 전환하면 "비공개로 바뀌었어요" 토스트가 뜬다.
3. 전환 직후 현재 적용 중인 필터가 다시 계산되어 목록에 반영된다.

### 3. 편지 작성 (F27)

1. 하단 CTA "편지 쓰기"를 누르면 오늘 날짜("오늘, 9월 29일 (화)에 남겨요") 기준 작성 바텀시트가 열리고 삭제 버튼은 숨겨진다.
2. 본문을 비운 채 저장을 누르면 저장되지 않고 입력창에 포커스만 이동한다.
3. 본문을 입력하고 공개 토글을 설정한 뒤 저장하면 오늘 날짜 그룹(없으면 새로 생성)의 맨 위에 새 카드가 추가되고 보관 통수가 1 늘며 "편지가 잘 보관됐어요" 토스트가 뜬다.
4. 취소 버튼 또는 딤 영역을 누르면 입력 내용을 저장하지 않고 바텀시트가 닫힌다.

### 4. 편지 수정·삭제 (F27)

1. 카드의 태그 버튼이 아닌 본문 영역을 누르면 "편지 수정" 바텀시트가 열리고 기존 본문·공개 여부가 채워지고 작성일 안내가 "{날짜 그룹 표기}에 남긴 편지예요"(예: "9월 28일 (월)에 남긴 편지예요")로 바뀌며 삭제 버튼이 함께 노출된다.
2. 저장하면 해당 카드의 본문과 공개 여부만 갱신되고 목록 내 위치는 그대로 유지된다.
3. "이 편지 삭제하기"를 누르면 확인 절차 없이 즉시 카드가 삭제되고 보관 통수가 줄며 "편지를 삭제했어요" 토스트가 뜬다.
4. 삭제로 인해 날짜 그룹에 편지가 하나도 남지 않으면 해당 날짜 그룹 전체가 목록에서 사라진다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 필터 결과 없음 | 목록 대신 빈 상태 안내만 표시 |
| 본문 미입력 상태로 저장 시도 | 저장되지 않고 입력창에 포커스 이동, 시트는 닫히지 않음 |
| 오늘 날짜에 기존 편지가 없는 상태로 새 편지 저장 | "오늘 남긴 편지" 캡션과 함께 새 날짜 그룹이 맨 위에 생성됨 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 시안은 편지 개수·글자 수 제한이 없다고 안내하는데, 실제 서비스에서도 무제한으로 둘지 확정 필요
- 삭제 버튼을 누르면 확인 모달 없이 즉시 삭제되는데, 되돌리기 없는 즉시 삭제로 확정할지 검토 필요
