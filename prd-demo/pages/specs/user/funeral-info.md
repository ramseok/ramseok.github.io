# P17 장례 정보

> URL `/farewell/funeral-info` · 대상 **사용자** · 관련 기능 F18 (F43과 연동)

이별 준비 중인 보호자가 장례 방식과 예상 비용을 미리 비교하고, 우리 지역에서 관할 기관에 정식 등록된 장묘업체를 찾아 전화로 문의할 수 있는 화면이다. 준비 체크리스트(P15)에서 진입하며, 뒤로가기는 다시 준비 체크리스트로 돌아간다.

## 동작 정의

### 1. 장례 방식 비교 (F18)

1. 개별 화장(25만 ~ 60만원), 합동 화장(8만 ~ 20만원), 자연장 · 수목장(30만 ~ 80만원) 3개 카드가 항상 고정 노출되며, 방식명 우측에 비용 범위를, 그 아래에 각 방식의 특징을 짧은 설명으로 보여준다.
2. 섹션 제목 우측에 "비용은 업체마다 달라요"라는 보조 문구가 붙어, 표시된 금액이 확정 견적이 아님을 알린다.
3. 방식 목록 아래에는 개인 매장 불가·정식 등록 업체 이용 필수라는 법적 유의사항이 고정 문구로 표시된다.

### 2. 지역별 등록 업체 탐색 (F18, F43)

1. 사용자가 지역 칩(서울/경기/인천/대전/대구/부산/제주)을 누르면 해당 지역의 업체 카드만 남고 나머지는 숨겨지며, 선택한 칩에 체크 표시와 활성 스타일이 적용된다.
2. "전체" 칩을 누르면 모든 지역의 업체가 다시 보인다. 진입 시 기본값은 "전체"다.
3. 각 업체 카드는 위에서부터 업체명과 "주소 · 전화번호", 방식별 비용 태그(개별화장·합동화장·수목장 중 해당 항목만), 하단 좌측의 "등록 검증일 YYYY.MM.DD" 표시와 우측 "전화 문의" 버튼 순으로 보여준다.
4. 시안에서는 서울 2곳, 경기 2곳, 인천 1곳, 대전 1곳, 대구 1곳, 부산 1곳 — 총 8개 업체가 더미 데이터로 고정되어 있고, 제주는 등록 업체가 없어 빈 상태로 연결된다.
5. **정식 등록 업체만 노출하는 정책**: 목록에 노출되는 업체는 관할 기관에 정식 등록이 확인된 곳만이며, 등록 여부와 검증일은 관리자 화면(P33 제휴 업체 관리, F43)에서 등록·수정한다. 이 화면에서 노출 여부를 직접 켜고 끄는 조작은 없다 — 등록 상태 변경은 어드민 쪽 작업이다.
6. 업체 카드의 "전화 문의" 버튼을 누르면 `tel:` 링크로 즉시 전화 연결을 시도한다(모바일 다이얼러 호출).

### 3. 즐겨찾기·빈 상태 처리 (F18)

1. 업체 카드 상단 행 우측의 하트 아이콘을 누르면 즐겨찾기 on/off가 토글되고, 하단에 "즐겨찾기에 담아뒀어요" 또는 "즐겨찾기에서 뺐어요" 토스트가 뜬다. 시안에서는 이 상태가 새로고침 시 저장되지 않는다(휘발성).
2. 선택한 지역에 업체가 하나도 없으면 카드 목록 대신 빈 상태(지도 아이콘 + "이 지역은 아직 정식 등록이 확인된 업체가 없어요")가 보이고 "전체 지역 다시 보기" 버튼이 나타난다.
3. 빈 상태의 버튼을 누르면 지역 필터가 "전체"로 초기화되고 "전체 지역을 다시 보여드릴게요" 토스트가 뜬다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 지역에 등록 업체 없음(예: 제주) | 업체 카드 대신 빈 상태 노출, "전체 지역 다시 보기" 버튼으로 복구 |
| 즐겨찾기 토글 | 하트 아이콘 채움 전환 + 토스트, 서버 저장 없음(시안 한정) |
| 전화 문의 클릭 | `tel:` 링크로 다이얼러 연결 시도, 통화 성사 여부는 화면에서 확인 불가 |
| 업체 등록 취소·정보 변경 | 시안에는 표현되지 않음. 개발 반영 시 P33에서 등록 취소된 업체는 즉시 이 목록에서 제외되어야 한다 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 즐겨찾기 데이터를 서버에 저장할지, 저장한다면 다른 페이지(예: 마이페이지)에서도 노출할지
- 지역 목록이 8개 고정인지, 추후 시·군·구 단위 세분화가 필요한지
- 등록 검증일 갱신 주기(F43 정책)와 검증일이 오래된 업체를 화면에서 어떻게 구분 표시할지
