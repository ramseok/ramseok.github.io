# P13 추억 타임라인

> URL `/timeline` · 대상 **사용자** · 관련 기능 F13

다이어리·버킷리스트 완료·소리/발도장·편지·(선택 시) 병원 방문 기록을 시간순으로 자동 통합해 하나의 목록으로 보여주는 화면이다. 사용자는 연도·유형으로 좁혀보고, 항목을 눌러 원래 작성했던 화면(P9~P12, P14, P16, P20)의 상세로 이동한다. 하단 탭바 "함께하기" 진입점이며, 홈(P4)·다이어리 목록(P9)·소리·발도장 보관함(P12)·버킷리스트(P14)에서도 들어올 수 있다.

## 동작 정의

### 1. 시간순 통합 기록 표시 (F13)

1. 화면에 진입하면 다이어리·버킷리스트 완료·소리/발도장·편지 기록이 날짜 최신순으로 하나의 목록에 자동 통합되어 표시된다.
2. 각 기록 카드는 날짜(요일 포함), 기록 유형 태그(아이콘+명칭), 제목, 본문 2줄 요약을 보여준다.
3. 병원 방문 기록은 건강 기록으로 분류되어 초기 목록에서는 항상 숨겨진다(추억 중심 구성).
4. "전체 기록" 제목 우측의 "{n}개"는 현재 필터 조건에서 노출 중인 기록 건수를 실시간으로 표시한다.
5. 기록 카드를 누르면 해당 기록을 작성했던 원본 화면(다이어리 P10, 병원 방문 P11, 버킷리스트 P14, 소리·발도장 P12, 편지 P16/P20)의 상세로 이동한다.
6. 좌측 레일의 세로선은 마지막으로 보이는 기록에서 끊긴다.

### 2. 연도·유형 필터 (F13)

1. 연도 칩(전체/2026/2025/2024) 중 하나를 누르면 해당 연도의 기록만 남고 목록이 즉시 갱신된다.
2. 유형 칩(전체/다이어리/버킷리스트/소리·발도장/편지) 중 하나를 누르면 해당 유형의 기록만 남고 목록이 즉시 갱신된다.
3. 연도 필터와 유형 필터는 동시에 적용되어 두 조건을 모두 만족하는 기록만 노출된다.
4. 두 필터 모두 한 번에 하나의 값만 선택 가능하며, 선택한 칩은 강조(active) 표시된다.

### 3. 병원 방문 기록 표시 토글 (F13)

1. "병원 방문 기록도 보기" 스위치는 기본적으로 꺼져 있으며, 병원 방문 기록은 목록에서 제외된다.
2. 스위치를 켜면 병원 방문 기록이 목록에 포함되고 "병원 방문 기록도 함께 보여드려요" 토스트가 뜬다.
3. 스위치를 켜도 유형 필터가 "전체"가 아닌 다른 값으로 선택되어 있으면 병원 방문 기록은 노출되지 않는다.
4. 스위치를 다시 끄면 병원 방문 기록이 제외되고 "병원 방문 기록을 다시 숨겼어요" 토스트가 뜬다.

### 4. 빈 상태 및 필터 초기화 (F13)

1. 연도·유형·병원 방문 조건을 모두 반영했을 때 노출할 기록이 하나도 없으면 목록 대신 "이 조건에 맞는 기록이 아직 없어요" 빈 상태와 `필터 초기화` 버튼이 표시된다.
2. `필터 초기화` 버튼을 누르면 연도·유형 필터가 모두 "전체"로, 병원 방문 스위치는 OFF로 되돌아가고 "필터를 초기화했어요" 토스트가 뜬다.

### 5. 더 살펴보기 (F13)

1. "다이어리 전체 보기"를 누르면 목록형·캘린더형으로 다이어리를 모아보는 화면(P9)으로 이동한다.
2. "하늘로 보내는 편지"를 누르면 이별 후 작성하는 편지함 화면(P20)으로 이동한다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 필터 조건에 맞는 기록 없음 | 목록 숨기고 빈 상태 + `필터 초기화` 버튼 노출 |
| 병원 방문 스위치 ON + 유형 필터가 특정 유형(전체 아님) | 병원 방문 기록은 계속 숨김 (유형 필터가 우선) |
| 시안 데이터 | 총 12건 더미(다이어리 4·버킷리스트 3·소리/발도장 2·편지 1·병원 방문 2)로 고정, 실제 서비스에서는 사용자별 실 기록으로 대체 (개발 반영 시) |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |
