# P23 추모 확장 (앨범 제작 · AI 회고록)

> URL `/memorial/extras` · 대상 **사용자** · 관련 기능 F29, F30 · **모두 P2(고도화) 단계**

무지개다리로 떠난 반려견의 타임라인 사진을 실물 상품으로 제작 주문하거나, 그동안 쌓인 기록을 바탕으로 AI가 생애 회고록 초안을 만들어주는 확장 화면이다. "앨범 제작" 탭과 "AI 회고록" 탭 2개로 구성되며, 메모리얼 페이지 관리(P18)의 "더 살펴보기"에서 진입한다.

## 동작 정의

### 1. 탭 전환 (공통)

1. "앨범 제작" / "AI 회고록" 탭을 누르면 해당 패널만 보이고 본문 스크롤이 맨 위로 이동한다.
2. 진입 시 기본으로 "앨범 제작" 탭이 활성 상태다.
3. 탭 바는 본문을 아래로 스크롤해도 화면 상단(헤더 바로 아래)에 고정되어 계속 보인다.

### 2. 사진 고르기 (F29)

1. 사진 그리드의 항목을 누르면 선택 표시(테두리 강조 + 체크 배지)가 토글되고, 상단 "N장 선택" 카운터가 즉시 갱신된다.
2. 시안에서는 타임라인 사진 9장이 아이콘 자리표시로 고정 표시된다(실제 이미지 원본 대신 더미 자리표시).
3. "타임라인 전체 보기" 링크를 누르면 추억 타임라인(P13, timeline.html)으로 이동한다.

### 3. 상품 종류 선택 (F29)

1. 포토북·액자·미니 굿즈 칩 중 하나를 누르면 해당 칩이 활성화되고, 아래 카드의 아이콘·설명·가격이 선택한 상품 정보로 바뀐다.
2. 기본 선택 상품은 "포토북"(20페이지 하드커버, 28,000원부터)이며, 다른 두 상품도 시안에 고정 문구·가격으로 정의돼 있다(액자 19,000원부터, 미니 굿즈 15,000원부터).

### 4. 배송 정보·주문 요청 (F29)

1. 받는 사람·연락처·배송 주소 입력칸에는 더미 값(김서현, 010-2345-6789, 서울시 마포구 성산로 12길 8)이 기본으로 채워져 있다.
2. 사진을 한 장도 고르지 않고 "주문 요청하기"를 누르면 "사진을 1장 이상 골라주세요" 토스트가 뜨고 주문이 접수되지 않는다.
3. 사진은 골랐지만 배송 주소를 비운 채 누르면 "배송 주소를 입력해주세요" 토스트가 뜨고 주문이 접수되지 않는다.
4. 두 조건을 모두 만족하면 주문 내역 목록 맨 위에 "[상품명] 주문 · 사진 N장" 항목이 "접수됨" 태그와 함께 추가되고, "주문 요청이 인쇄 업체로 전달됐어요" 토스트가 뜬 뒤 선택했던 사진의 선택 표시가 모두 해제된다.
5. 주문 정보는 정식 계약된 외부 인쇄 업체로 전달된다는 안내 문구가 버튼 아래 항상 표시된다.

### 5. 주문 내역 (F29)

1. 진입 시 기존 주문 2건이 고정 표시된다: 액자 주문(8월 22일 접수, 배송 완료), 포토북 주문(9월 10일 접수, 제작 중).
2. 신규 주문은 접수일이 시연 오늘 날짜(9월 29일)로 고정 표시되며 상태 태그는 항상 "접수됨"이다(개발 반영 시 실제 주문일·인쇄 업체 진행 상태로 대체).

### 6. AI 초안 생성 (F30)

1. "AI 초안 생성 요청" 버튼을 누르면 버튼이 비활성화되며 문구가 "초안을 만들고 있어요…"로 바뀌고, 안내 문구는 "다이어리 32건 · 편지 2통 · 타임라인을 살펴보는 중…"으로 바뀐다.
2. 약 0.9초 후 회고록 초안 텍스트영역에 고정된 더미 회고록 문장이 채워지고, 버튼은 "다시 생성하기"로 복귀하며, 안내 문구는 "초안 생성됨 · 방금 전 · 저장 전이라 아직 보이지 않아요"로 바뀌고 "초안이 만들어졌어요. 편하게 고쳐보세요" 토스트가 뜬다.
3. 시안에서는 다이어리·편지·타임라인 실 데이터를 분석하지 않고 고정 더미 텍스트 1종만 노출된다(개발 반영 시 실제 AI 생성 결과로 대체).
4. "다시 생성하기"를 다시 눌러도 같은 더미 텍스트가 재노출된다(시안 한정).

### 7. 초안 편집·저장 (F30)

1. 회고록 초안 텍스트영역은 자유롭게 고쳐 쓸 수 있다.
2. 텍스트가 비어 있는 상태(초안 미생성 또는 전부 지운 상태)에서 "회고록 저장하기"를 누르면 "먼저 초안을 생성하거나 내용을 적어주세요" 토스트가 뜨고 저장되지 않는다.
3. 내용이 있는 상태에서 저장하면 안내 문구가 "마지막 저장 · 9월 29일 14:02"로 바뀌고 "회고록을 잘 저장해뒀어요" 토스트가 뜬다.
4. 저장 전에는 추모관에 노출되지 않으며, 저장 후에도 보호자가 확인한 뒤에만 반영된다는 안내가 항상 표시된다.
5. 목소리 합성 기능과 "보리가 보내는 메시지" 형식의 생성은 이 화면에 없으며, 정책상 제공하지 않는다(안내 배너에 명시).
