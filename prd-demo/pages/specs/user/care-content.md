# P21 케어 콘텐츠 (마음 돌봄)

> URL `/care` · 대상 **사용자** · 관련 기능 F19, F20, F21 (F22는 하단 커뮤니티 진입 카드로만 연결)

이별을 겪었거나 준비 중인 보호자가 애도 아티클을 읽고, 상담 기관 연락처를 확인하고(무지개다리 상태에서는) 이별 후 행정 절차까지 한 화면에서 살펴보는 케어 허브다. 하단 탭바 "마음 돌봄"에서 모든 반려동물 상태에서 상시 진입 가능하며, 자가 진단·점수화 없이 콘텐츠 열람과 전화 연결만 제공한다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | "마음 돌봄" 타이틀(뒤로가기 없음, 탭바 진입 화면) | - |
| 인트로 | "마음 돌봄" 캡션 + "천천히, 마음도 함께 돌봐요" 타이틀 + "누구에게나 슬픔의 속도는 달라요. 필요할 때 하나씩 살펴보세요." 설명 | - |
| 탭 | 아티클(기본 활성) · 상담 기관 · 행정 안내(무지개다리 상태에서만 노출), 스크롤해도 본문 상단에 고정 | F19, F20, F21 |
| 아티클 패널 | 애도·가족 대화·재입양·추억 정리 등 7개 아티클을 한 묶음 리스트 안의 아코디언 행(행 사이 구분선)으로 표시 | F20 |
| 상담 기관 패널 | 자가진단 없음 안내 배너 + 상담 기관 카드 6곳(연락처·운영시간·전화 버튼) | F21 |
| 행정 안내 패널 | 최종 점검일 배너 + 동물등록 사망 신고 절차(4단계) + 사체 처리 유의사항 | F19 |
| 커뮤니티 안내 카드 | "함께 나누는 이야기" 섹션, 클릭 시 community.html(P22)로 이동 | F22 |

## 동작 정의

### 1. 탭 전환 및 행정 안내 노출 조건 (F19, F20, F21)

1. 화면 진입 시 아티클 탭이 기본 활성 상태로 표시된다.
2. 탭을 누르면 해당 패널만 보이고 나머지 패널은 숨겨지며, 패널 전환 시 본문 스크롤이 맨 위로 이동한다. 탭 바는 본문을 아래로 스크롤해도 화면 상단(헤더 바로 아래)에 고정되어 계속 보인다.
3. "행정 안내" 탭 버튼과 패널은 기본적으로 화면에 없다(hidden). `?state=rainbow` 쿼리 파라미터 또는 저장된 반려동물 상태(localStorage `rd-pet-state`)가 "무지개다리"일 때만 탭 버튼이 나타난다. 상태 우선순위는 URL 파라미터 > 저장값 > 기본값(함께하는 중)이다.
4. 무지개다리 상태로 진입한 화면에서 `?tab=admin`을 함께 지정하면 시작 탭이 자동으로 "행정 안내"로 선택된다. 행정 안내 탭이 아직 노출되지 않은 상태(무지개다리가 아닌 경우)라면 `?tab=admin`은 무시되고 아티클 탭이 그대로 유지된다.
5. 시안에서 반려동물 상태는 실제 서버 세션이 아닌 쿼리 파라미터·로컬 저장값으로만 시뮬레이션되며, 개발 반영 시 실제 반려동물의 이별 처리 여부에 따라 서버에서 노출 여부를 결정해야 한다.

### 2. 아티클 열람 (F20)

1. "아티클" 탭에는 슬픔의 순서·아이와 이별 이야기·재입양 고민·사진 정리·가족과 슬픔 나누기·힘든 밤·기일 준비 등 총 7개 아티클이 하나의 리스트 묶음 안에 구분선으로 나뉜 행으로 고정 노출된다.
2. 각 행은 아이콘, 제목, 카테고리·예상 읽기 시간(예: "애도 과정 이해하기 · 5분")을 헤더에 보여준다.
3. 행을 누르면 아코디언이 펼쳐지며 행 아래에 본문 텍스트 박스가 나타나고 우측 화살표 아이콘이 180도 회전한다. 다시 누르면 접힌다. 여러 행을 동시에 펼쳐둘 수 있다.
4. 시안에서는 7건의 아티클 본문이 고정 텍스트로 하드코딩되어 있으며, 실제로는 CMS에서 관리되는 콘텐츠로 대체되어야 한다(F41 연동 예정).

### 3. 상담 기관 연결 (F21)

1. "상담 기관" 탭 상단에는 "자가 진단이나 점수화 없이, 전문 상담 기관과 바로 연결해드려요" 안내 배너가 항상 표시된다.
2. 기관 카드 6곳이 목록으로 보이며, 각 카드는 기관명·운영 시간·상담 방식(전화/화상/대면)·상태 태그("초기 상담 무료" 또는 "예약제" 또는 "24시간 운영")와 전화 번호 버튼을 보여준다.
3. "전화하기" 버튼을 누르면 `tel:` 링크로 모바일 다이얼러 연결을 시도한다. 화면에서 통화 성사 여부는 확인할 수 없다.
4. **시안에 등장하는 6개 상담 기관(마음이음 펫로스 상담센터, 햇살심리상담센터, 위드동물심리지원센터, 보리와 마음클리닉, 24시 마음지킴이 상담전화, 서로돌봄 심리상담센터)은 모두 가상의 예시 기관과 연락처다.** 실제 서비스에서는 제휴 업체 관리(F43)에서 등록한 실제 상담 기관 정보로 교체되어야 한다.

### 4. 이별 후 행정 안내 (F19, 무지개다리 상태 전용)

1. 패널 상단에 "법령 기반 안내예요. 최종 점검일 2026년 9월 1일" 배너가 표시된다.
2. "동물등록 변경(사망) 신고" 카드에 번호가 매겨진 4단계 절차가 나열된다: ① 사망일로부터 30일 이내 신고 ② 국가동물보호정보시스템 온라인 또는 관할 시·군·구청 방문 신청 ③ 동물등록증·신분증 필요(대리 신청 시 위임장) ④ 접수 시 등록 정보 '말소' 처리, 새 반려동물은 신규 등록 절차 필요.
3. "사체 처리 관련 유의사항" 카드에는 폐기물관리법에 따른 처리 방법(종량제 봉투 배출, 동물병원 위탁, 등록된 동물장묘시설 이용)과 임의 매립·하천 투기 금지 안내가 표시된다.
4. 카드 하단에 "법령은 지자체별로 다를 수 있어요. 정확한 절차는 관할 기관에 다시 확인해 주세요"라는 면책 문구가 고정 노출된다.

### 5. 커뮤니티 진입 (F22)

1. 화면 최하단에 "함께 나누는 이야기" 섹션과 커뮤니티 안내 카드가 항상 표시된다(반려동물 상태와 무관).
2. 카드를 누르면 커뮤니티 화면(P22, community.html)으로 이동한다. 이 페이지 자체에는 글 작성·댓글 등 F22의 세부 기능은 구현되어 있지 않다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 행정 안내 미노출 상태(함께하는 중/이별 준비) | 행정 안내 탭 버튼이 화면에 존재하지 않는다(hidden), `?tab=admin`도 무시된다 |
| `?state=rainbow`로 진입 | 행정 안내 탭 버튼이 즉시 나타난다(패널은 탭 클릭 시에만 열림) |
| 아코디언 접기/펼치기 | 새로고침 시 모든 카드가 다시 접힌 상태로 초기화된다(휘발성) |
| 전화 문의 클릭 | `tel:` 링크로 다이얼러 연결 시도만 하며 통화 결과는 화면에 반영되지 않는다 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 실제 서비스에서 상담 기관 6곳을 어떤 제휴 기준으로 선정·노출할지(F43 정책)
- 반려동물 상태(무지개다리 여부) 판정을 서버 세션 기준으로 전환할 때 상태 전환 시점(F19 진입 조건)
- 아티클 콘텐츠 CMS 반영 시 카테고리·읽기 시간 표기 방식 유지 여부
