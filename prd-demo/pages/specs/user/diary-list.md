# P9 일상 다이어리 목록 (무지개 일기(가칭))

> URL `/diary` · 대상 **사용자** · 관련 기능 F9, F36

보호자가 반려동물과 보낸 하루하루를 사진·영상·글·기분 태그로 남기고, 지금까지 쌓인 기록을 목록형 또는 캘린더형으로 훑어보는 화면이다. 하단 탭바의 "기록" 탭 진입점이며, 카드나 날짜를 탭하면 다이어리 작성 화면으로 넘어간다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 타이틀 "다이어리" + 우측 연필 아이콘(새 다이어리 쓰기) | F9 |
| 인사 영역 | 현재 월(2026년 9월) 표시 + "보리와 함께한 날들" 문구 + 안내 카피 | - |
| 보기 전환 | 목록형·캘린더형 세그먼트 버튼 + 우측 "타임라인" 바로가기 링크 | F9 |
| 기분 태그 필터 | 전체·행복·평온·아픔·특별한 날 칩 5개 (목록형에서만 노출) | F9 |
| 다이어리 카드 목록 | 최신순 2열 갤러리 — 가장 최근 기록 1건은 풀폭 대형 카드, 나머지 8건은 2열. 카드마다 대표 사진(좌상단에 기분 태그 오버레이), 날짜, 미리보기 텍스트 2줄, 카드 전체가 링크 | F9 |
| 캘린더형 | 월 이동 버튼, 요일 헤더, 날짜별 기분 점 표시, 오늘 강조, 범례 | F9 |
| 용량 안내 배너 | 목록형·캘린더형 공통으로 콘텐츠 아래(하단 탭바 위)에 노출. 보관 중인 사진·영상 수, 저장 용량 진행바, 영상 업로드 제한 안내 | F36 |
| 하단 탭바 | 홈·기록·함께하기·마음 돌봄·마이 5개, "기록" 탭 활성 | - |

## 동작 정의

### 1. 목록형·캘린더형 전환 (F9)

1. 기본 진입 시 목록형이 선택되어 있고, 기분 태그 필터와 다이어리 카드 목록이 보인다.
2. "캘린더형" 버튼을 누르면 목록형 영역과 기분 태그 필터가 숨겨지고 캘린더가 표시되며, 버튼 활성 상태가 바뀐다.
3. "목록형" 버튼을 다시 누르면 캘린더가 숨겨지고 카드 목록과 기분 태그 필터가 다시 보인다.
4. 보기를 전환할 때마다 본문 스크롤이 맨 위로 초기화된다.
5. "타임라인" 링크를 누르면 추억 타임라인 화면(timeline.html)으로 이동한다.

### 2. 기분 태그 필터링 (목록형 전용) (F9)

1. 칩(전체·행복·평온·아픔·특별한 날) 중 하나를 선택하면 선택한 기분이 붙은 카드만 남고 나머지는 숨겨진다.
2. 선택한 칩만 활성 스타일로 표시되고 이전 선택은 해제된다.
3. 선택한 기분에 해당하는 카드가 하나도 없으면 카드 목록 대신 "이 기분으로 남긴 기록이 아직 없어요" 안내 문구가 노출된다. 시안 더미 데이터는 네 기분 모두 최소 1건 이상 있어 실제로는 발생하지 않는다.

### 3. 다이어리 카드 진입 (F9)

1. 카드는 최신 날짜순(9월 23일 → 9월 2일)으로 정렬되며, 첫 카드(가장 최근 기록)는 2열 전체 폭을 차지하는 큰 카드로, 이후 카드는 2열 갤러리로 배치된다.
2. 카드를 탭하면 다이어리 작성 화면(diary-write.html)으로 이동한다. 시안에서는 모든 카드가 신규 작성 화면과 동일한 링크로 연결되어 있다.
3. 헤더의 연필 아이콘을 누르면 같은 작성 화면으로 이동해 새 다이어리를 쓴다.

### 4. 캘린더형 보기 (F9)

1. 캘린더에는 해당 월의 날짜가 요일별로 배치되고, 기록이 있는 날짜는 칸 하단에 기분별 색 점이 표시된다(행복 노랑·평온 민트·특별한 날 파랑·아픔 회색).
2. 날짜 칸을 탭하면 기록 유무와 관계없이 다이어리 작성 화면으로 이동한다.
3. "오늘" 날짜 칸은 테두리로 강조 표시된다. 시안에서는 9월 29일(오늘) 칸이 강조되어 있다.
4. "이전 달" 버튼을 누르면 8월 달력으로 전환되고 월 라벨이 "2026년 8월"로 바뀌며 하단에 토스트 "8월 기록을 보고 있어요"가 뜬다. 이전 달 버튼은 비활성화되고 다음 달 버튼이 활성화된다.
5. "다음 달" 버튼을 누르면 9월 달력으로 돌아오고 토스트 "9월 기록을 보고 있어요"가 뜨며 다음 달 버튼이 비활성화되고 이전 달 버튼이 활성화된다.
6. 시안은 8월·9월 두 달치 데모 데이터만 갖고 있어 그 밖의 월로는 이동할 수 없다.

### 5. 미디어 보관 안내 (F36)

1. 목록형·캘린더형 공통으로 콘텐츠 아래에 놓인 배너에 현재까지 보관 중인 사진·영상 수량, 저장 용량 사용률(진행바), 영상 업로드 제한(1개당 최대 1분)을 안내한다.
2. "원본은 따로 저장되니 걱정 마세요" 문구로 업로드 미디어가 리사이즈·원본 백업 처리됨을 알린다. 이 배너 자체에는 클릭 인터랙션이 없다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 선택한 기분 태그에 해당 카드 없음 | 카드 목록 숨김 + "이 기분으로 남긴 기록이 아직 없어요" 안내 노출 (시안 더미 데이터로는 미발생) |
| 8월 이전/9월 이후 달 이동 시도 | 이동 불가 — 해당 방향 버튼이 비활성화되어 있음 (데모 데이터 범위 밖) |
| 캘린더 특정 날짜에 기록 없음 | 색 점 없이 날짜 숫자만 노출, 탭하면 작성 화면으로 이동 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 다이어리 카드 클릭 시 시안은 모두 신규 작성 화면과 동일 링크로 연결되어 있다. 개발 반영 시 해당 날짜 기록을 불러오는 수정 모드로 진입해야 하는지 확인 필요.
- 캘린더형에서 8월 이전·10월 이후로 이동(스크롤 로딩 등)이 필요한지, 아니면 데이터가 있는 달까지만 제공할지 확인 필요.
