# P5 반려견 관리 (다견 등록 · 이별 준비 전환)

> URL `/mypage/pets` · 대상 **사용자** · 관련 기능 F2, F4, F8, F38

마이페이지에서 들어와 등록된 반려견 목록을 확인하고, 반려견별 프로필을 수정하거나 상태(함께하는 중/이별 준비)를 직접 전환하는 화면이다. 무지개다리 전환 자체는 이 화면이 아니라 각 카드의 "무지개다리를 건넜어요" 버튼을 통해 P6으로 넘어가서 처리한다. 새 반려견 등록도 이 화면의 바텀시트에서 이뤄지며, 무료 플랜 5마리 한도가 여기서 적용된다.

---

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기(마이페이지로) · "반려견 관리" 제목 | - |
| 안내 문구 | "등록한 아이들의 정보를 살펴보고, 필요할 때 상태를 바꿔요." | - |
| 우리 아이들 | 섹션 제목 우측 등록 수("N / 5마리") + 반려견 카드 목록 | F2, F38 |

| 토스트 | 저장/전환/등록/한도초과 안내 (3초) | - |

## 동작 정의

### 1. 반려견 목록·상태 배지 (F2)

1. "우리 아이들" 제목 우측에 등록 수(예: 2 / 5마리)가 표시되고, 그 아래 반려견 카드가 세로로 나열된다.
2. 각 카드는 이름, 상태 배지("함께하는 중"/"이별 준비"/"무지개다리"), 견종·성별·나이(예: 말티즈 · 여아 · 만 14살)와 그 아래 생일(예: 2012.06.02생), 정보 박스 안의 함께한 지 일수와 등록번호(마스킹) 또는 "동물등록번호 미등록" 표시로 구성된다.
3. 보리 카드는 시연용으로 상태가 세 가지(함께하는 중/이별 준비/무지개다리)로 바뀔 수 있으며, URL의 `?state=` 파라미터 또는 이전에 저장된 값을 따른다(시안 한정 시연 스위처).
4. 보리가 무지개다리 상태이면 "함께한 지 N일" 대신 "입양일 ~ 이별일"(첫 줄)과 "함께한 N일"(둘째 줄) 두 줄 기간 문구가 표시되고, "이별 준비로 전환"·"무지개다리를 건넜어요" 버튼이 숨겨진다. 정보 박스 아래에 안내 "잘못 남기셨다면 10월 1일(목)까지 이전 상태로 되돌릴 수 있어요."와 "되돌리기 (10월 1일까지)" 버튼이 나타나며, "정보 수정" 버튼은 그대로 남는다.
5. 콩이 카드는 무지개다리 배지·기간 표시 요소가 아예 없어 함께하는 중/이별 준비 두 상태만 오간다.

### 2. 정보 수정 (F2)

1. "정보 수정" 버튼을 누르면 카드 하단에 인라인 폼(이름*, 생년월일*, 견종, 성별, 입양일, 등록번호)이 펼쳐지고, 다시 누르면 접힌다.
2. "저장"을 누르면 이름 입력값만 카드 제목에 반영되고 폼이 닫히며 토스트 "OO의 정보를 저장했어요"가 뜬다. 시안에서는 이름 외 필드의 실제 저장과 필수값(이름·생년월일) 검증 로직은 구현되어 있지 않다.
3. "취소"를 누르면 입력값 반영 없이 폼만 닫힌다.
4. 성별 세그먼트는 클릭한 버튼만 활성(active)으로 바뀐다.
5. 카메라 아이콘을 누르면 토스트 "사진 선택 화면은 준비 중이에요"만 뜨고 실제 사진 변경은 일어나지 않는다.

### 3. 이별 준비 전환·복귀 (F4)

1. "이별 준비로 전환" 버튼을 누르면 확인 모달이 뜬다. 제목/본문은 "OO의 이별을 준비할까요? 천천히 준비해도 괜찮아요. 언제든 다시 되돌릴 수 있어요."이다.
2. 이미 이별 준비 상태인 카드는 버튼 텍스트가 "함께하는 중으로 복귀"로 바뀌어 있고, 이때 모달 문구도 "OO이(가) 함께하는 중으로 돌아올까요? 작성해둔 체크리스트와 편지는 그대로 남아있어요."로 바뀐다.
3. "아니요"를 누르면 아무 변화 없이 모달만 닫힌다.
4. "네, 전환할게요/되돌릴게요"를 누르면 배지와 버튼 텍스트가 즉시 바뀌고 토스트가 뜬다.
5. 보리 카드의 전환 결과만 로컬 저장소(rd-pet-state)에 저장되어 홈(P4)·전환(P6) 화면과 상태가 이어진다. 그 외 카드의 전환은 화면을 새로고침하면 "함께하는 중"으로 초기화된다(시안 한정).
6. "무지개다리를 건넜어요" 버튼은 카드별로 rainbow-transition.html로 이동한다(반려견 이름 쿼리 포함). 실제 무지개다리 전환 처리는 P6에서 이뤄진다.

### 4. 새 반려견 등록 (F2, F38)

1. "새로운 아이 등록하기"를 누르면 바텀시트가 열린다.
2. 이름은 필수 — 비운 채 "등록하기"를 누르면 입력칸에 에러 표시가 뜨고 포커스가 이동하며 등록되지 않는다.
3. "태어난 날짜를 몰라요"를 체크하면 생년월일 입력칸이 숨겨지고 추정 나이 입력칸이 나타난다(해제 시 원복).
4. 등록 시 현재 카드 수가 5마리 이상이면 토스트 "무료 플랜은 최대 5마리까지 등록할 수 있어요"가 뜨고 시트만 닫히며 등록되지 않는다(F38 한도).
5. 5마리 미만이면 새 카드가 목록 맨 아래 추가된다. 이름·견종·성별은 카드에 반영되지만, 생년월일·입양일·등록번호 입력값은 반영되지 않고 항상 "오늘부터 함께해요"·"동물등록번호 미등록"으로 고정 표시된다(시안 한정). 등록 수 배지가 +1 되고 토스트 "OO이(가) 등록됐어요"가 뜬다.
6. 새로 추가된 카드도 정보 수정·이별 준비 전환·무지개다리 전환 버튼이 기존 카드와 동일하게 동작한다(이벤트 위임).

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 등록 5마리 도달 후 추가 등록 시도 | 토스트로 한도 안내 후 시트 닫힘, 카드 추가 안 됨 |
| 보리 상태가 무지개다리 | 이별 준비 전환·무지개다리 전환 버튼 숨김, 되돌리기 안내와 되돌리기 버튼 노출(정보 수정 버튼은 유지) |
| 콩이 등 보리 외 카드의 상태 전환 후 새로고침 | 로컬 저장 없어 함께하는 중으로 초기화된다(시안 한정) |
| 이름 미입력 상태로 등록 시도 | 입력칸 에러 표시 + 포커스 이동, 시트 유지 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 인라인 정보 수정에서 이름 외 필드(생년월일·견종·성별·입양일·등록번호)의 실제 저장 처리와 필수값 검증 로직
- 새 반려견 등록 시 생년월일/추정 나이/입양일/등록번호 입력값의 실제 저장 방식과 "함께한 지 N일" 자동 계산 로직
- 콩이 등 보리 외 반려견의 상태(이별 준비/무지개다리) 저장 방식 — 시안은 보리만 로컬 저장되어 있어 서버 저장 범위 확인 필요
