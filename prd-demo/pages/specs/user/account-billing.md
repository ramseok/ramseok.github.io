# P24 구독·결제·데이터 내보내기

> URL `/mypage/billing` · 대상 **사용자** · 관련 기능 F31, F32, F38

마이페이지에서 진입해 현재 이용 중인 플랜(무료/프리미엄)과 사용 용량을 확인하고, 플랜을 비교해 구독·해지하며, 반려견별 전체 기록을 ZIP으로 내려받는 화면이다. 구독이 끊기거나 결제가 실패해도 추모관과 기존 기록은 지워지지 않고 읽기 전용으로 유지된다는 원칙을 화면 중간 안내 배너로 반복해 보여준다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기(마이페이지) + "구독·결제" 제목 | - |

| 구독 가격 카드 | 프리미엄 월 요금, "언제든 해지 가능" 문구, 구독하기/해지하기 버튼(플랜 상태에 따라 하나만 노출) | F32 |

| 구독/해지 확인 모달 | 구독 시작·해지 각각의 확인 문구와 확인/취소 버튼 | F32 |
| 토스트 | 구독 시작·해지·ZIP 완료 시 하단 토스트 메시지 | - |

## 동작 정의

### 1. 현재 이용 현황·플랜 상태 반영 (F32, F38)

1. 시안은 기본값으로 **무료 플랜**을 보여주며, 제목 "무료 플랜 이용 중"·안내 문구 "기본 기능을 자유롭게 써보세요"·뱃지 "무료"·저장 용량(1.8GB/2GB, 90%)·반려견 등록(2/5)·영상 길이(1분)·테마(기본)를 표시한다.
2. 구독을 시작하면 위 값이 즉시 **프리미엄** 기준("프리미엄 플랜 이용 중", "모든 기능을 넉넉하게 써보세요", 뱃지 "프리미엄", 1.8GB/50GB, 4%, 2/무제한, 5분, 전체)으로 바뀌고 상단 버튼 라벨도 "프리미엄 살펴보기"에서 "구독 관리"로 바뀐다.
3. "프리미엄 살펴보기(구독 관리)" 버튼을 누르면 화면이 아래 플랜 비교 섹션으로 스크롤 이동한다.

### 2. 플랜 비교·구독/해지 (F32)

1. 플랜 비교 표의 무료/프리미엄 열 제목 옆에는 현재 이용 중인 플랜에만 "이용 중" 뱃지가 붙고, 플랜 전환 시 뱃지 위치도 함께 바뀐다.
2. "프리미엄 시작하기" 버튼을 누르면 구독 확인 모달이 열리고, 월 요금과 "해지해도 추모관·기록은 읽기 전용으로 유지된다"는 안내가 표시된다.
3. 모달에서 "네, 시작할게요"를 누르면 플랜이 프리미엄으로 전환되고, 결제 내역에 새 항목이 추가되며, "프리미엄 구독이 시작됐어요" 토스트가 뜬다.
4. 프리미엄 상태에서는 시작 버튼 대신 "프리미엄 해지하기" 버튼이 노출되며, 누르면 해지 확인 모달이 열린다.
5. 해지 모달에서 "네, 해지할게요"를 누르면 플랜이 무료로 되돌아가고, "프리미엄을 해지했어요. 추모관과 기록은 읽기 전용으로 유지돼요" 토스트가 뜬다(결제 내역은 그대로 남는다).
6. 모달은 "잠시 후에요" 버튼 또는 배경(딤 영역) 클릭으로 닫히며, 이때는 플랜 상태가 바뀌지 않는다.

### 3. 결제 내역 (F32)

1. 시안 초기 상태에는 결제 내역이 없어 "아직 결제 내역이 없어요" 빈 상태 문구가 표시된다.
2. 구독을 시작하면 빈 상태가 사라지고 목록으로 전환되며, "프리미엄 구독 결제 · 9월 29일 · 9,900원 · 결제 완료" 항목이 맨 위에 추가된다.
3. 해지해도 이미 쌓인 결제 내역 항목은 삭제되지 않는다.

### 4. 반려견별 ZIP 내보내기 (F31)

1. 보리·콩이 각 카드에 사진·영상·녹음 개수와 총 용량이 더미 수치로 고정 표시된다.
2. "ZIP 내려받기" 버튼을 누르면 버튼이 회전 아이콘과 "압축하는 중" 텍스트로 바뀌며 비활성화된다.
3. 약 1.4초 뒤 버튼이 "완료" 표시로 바뀌고 "OO의 기록을 ZIP으로 내려받았어요" 토스트가 뜬다.
4. 다시 약 2.2초 뒤 버튼은 "ZIP 내려받기" 원래 상태로 돌아와 재사용할 수 있다.
5. 이 내보내기 동작은 플랜(무료/프리미엄)과 무관하게 동일하게 노출·동작한다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 결제 내역 없음(초기 상태) | "아직 결제 내역이 없어요. 프리미엄을 시작하면 여기에 기록돼요" 빈 상태 문구 |
| 해지 후에도 데이터 접근 | 안심 안내 배너·모달 문구로 "추모관·기록은 삭제되지 않고 읽기 전용 유지(새 업로드만 제한)"를 반복 안내 |
| ZIP 버튼 중복 클릭 | 압축 중(disabled) 상태에서는 클릭이 무시된다 |
| 서비스 종료 시나리오 | 시안은 문구만 고정 노출하며 실제 90일 카운트다운·발송 로직은 없다 |
| 글자 크기 저장값(lg/xl) 있음 | 화면 전체 글자 크기가 확대되어 반영 |

## 확정 필요

- 플랜 가격·용량 수치 — 시안은 예시로 무료 2GB/반려견 5마리/영상 1분, 프리미엄 월 9,900원/50GB/무제한/영상 5분을 쓰고 있다. 실제 요금제 가격·용량은 고객사 확정 필요 (계약서 F32에도 "예시"로 표기됨)
- PG(결제대행사) 연동 방식 — 시안은 구독/해지를 프런트 상태 토글로만 시뮬레이션하며 실제 카드 등록·정기결제·PG사·환불 처리 방식은 정의되어 있지 않다. 개발 반영 시 확정 필요
- 결제 실패(카드 만료 등) 시 화면 노출 방식 — 계약서에는 "결제 실패 시 읽기 전용 유지"가 명시되나 시안에는 결제 실패 상태를 보여주는 화면이 없다
