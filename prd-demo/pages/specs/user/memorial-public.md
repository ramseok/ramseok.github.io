# P19 공개 추모관 (비회원·가족 방문자)

> URL `/m/:token` · 대상 **사용자(비회원 포함)** · 관련 기능 F24, F25, F27, F35, F37

공유 링크(`/m/:token`)로 들어온 외부 방문자가 반려견의 추모관을 열람하고 헌화·방명록을 남기는 화면이다. 로그인 없이 접근하며, 페이지 최상단에서 "보호자이신가요?" 진입점을 통해서만 로그인(P2)으로 넘어간다. 위에서부터 대표 정보 → 추억 사진 → 타임라인 → 편지 → 목소리 → 방명록 순서로 스크롤되며, 하단에 보호자 로그인 안내와 noindex 고지가 붙는다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 서비스 로고("무지개 일기") + "보호자이신가요?" 링크(로그인 이동) | F24 |
| 추모관 대표 영역 | 무지개 띠, 대표 사진, 이름, 함께한 기간·일수, 한마디, 꽃 남기기 버튼·누적 수 | F35, F25 |
| 대표 추억 사진 | 보호자가 고른 사진 6장, 그리드 배치 | F23, F35 |
| 함께한 시간(타임라인) | 가족이 된 날·생일·마지막 산책·무지개다리 건넌 날 4건 카드 | F35 |
| 하늘로 보내는 편지 | 공개(전체 공개) 편지만 날짜순 카드로 노출, 2줄 미리보기 | F27 |
| 목소리 | 녹음 1건, 재생/일시정지 토글 + 진행 바 | F35 |
| 방명록 | 비회원 작성 허용 안내, 이름·메시지 입력 폼, 등록 버튼, 목록(가족 태그·날짜·신고) | F25 |
| 보호자 진입 안내 | "로그인하고 페이지 관리하기" 링크, "검색엔진에 노출되지 않아요" 고지 | F24, F37 |

## 동작 정의

### 1. 추모관 열람 (F35, F23)

1. 방문자가 공유 링크로 접근하면 대표 사진·이름·함께한 기간·일수·한마디가 상단에 표시된다.
2. 대표 추억 사진(6장) 중 하나를 누르면 사진을 크게 보는 모달이 뜨고, 하단에 촬영 설명(캡션)이 표시된다. 이 모달에는 선택·다운로드 등 편집 기능이 없다.
3. "함께한 시간" 카드에는 가족이 된 날, 생일, 마지막 산책, 무지개다리를 건넌 날 4건이 고정 노출된다(시안 더미 데이터).

### 2. 꽃 남기기 · 목소리 재생 (F25, F35)

1. "꽃 남기기" 버튼을 누르면 헌화 수가 1 증가하고, 버튼에 스탬프 효과가 재생되며 "꽃을 남겨주셨어요. 보리에게 전할게요" 토스트가 뜬다.
2. 시안에서는 무료 헌화만 있으며 클릭할 때마다 제한 없이 증가한다(중복·1인 1회 제한 없음).
3. "보리 목소리" 카드의 재생 버튼을 누르면 재생/일시정지 아이콘이 토글되고 진행 바·라벨("재생 중 · …")이 바뀐다. 실제 오디오 재생은 시안에 연결되어 있지 않다.

### 3. 하늘로 보내는 편지 (F27)

1. 편지 섹션에는 보호자가 "공개"로 설정한 편지만 날짜 최신순으로 노출된다. 비공개 편지는 이 화면에 나타나지 않는다.
2. 각 카드에는 작성일과 "공개" 태그, 본문 2줄 미리보기만 있고, 전체 보기·상세 진입 기능은 시안에 없다.

### 4. 방명록 작성·목록 (F25, F26)

1. 상단 안내 문구로 보호자가 비회원 작성을 허용했음을 알린다(허용하지 않은 상태의 화면은 시안에 없음).
2. 이름을 비우고 등록하면 작성자명이 "익명"으로 저장된다.
3. 메시지를 비우고 등록을 누르면 입력창에 포커스가 가고 "보리에게 전할 메시지를 적어주세요" 토스트가 뜨며 등록되지 않는다.
4. 정상 등록 시 목록 맨 위에 "방금 전"으로 새 항목이 추가되고, 방명록 수 카운트가 1 증가하며, 입력창이 비워지고 "방명록에 마음을 남겼어요" 토스트가 뜬다.
5. 목록의 "가족" 태그는 가족 공유 구성원(이모 수진, 언니 은지 등)에게만 붙고, 그 외 방문자는 태그 없이 이름만 표시된다.
6. 새로 등록한 글은 신고·수정·삭제 없이 즉시 화면에 남으며, 보호자 승인 절차는 이 화면에 없다(관리는 P18에서 한다).

### 5. 신고 (F25, F26)

1. 각 방명록 항목의 깃발 아이콘을 누르면 신고 모달이 뜨고, 신고 사유(스팸·광고성 글 / 부적절한 표현 / 개인정보 노출 / 기타 4개 중 하나, 드롭다운)를 선택하고 상세 내용(선택)을 입력할 수 있다.
2. "신고하기"를 누르면 모달이 닫히고 "신고가 접수됐어요. 확인 후 처리할게요" 토스트가 뜨며, 해당 항목의 신고 버튼은 빨간색으로 바뀌고 비활성화("신고 접수됨")된다.
3. 신고된 글이 실제로 숨김·목록에서 제외되는지, 관리자 검토(P42 등)로 전달되는지는 이 화면에서 확인할 수 없다(개발 반영 시 처리).

### 6. 보호자 진입 (F24)

1. 헤더의 "보호자이신가요?"와 하단의 "로그인하고 페이지 관리하기"는 모두 로그인(P2)으로 이동하는 동일한 경로이며, 로그인 후 편집 화면(P18)으로 이어진다.
2. 화면 최하단에 "이 추모관은 검색엔진에 노출되지 않아요" 문구가 항상 표시된다(noindex 고지).

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 검색엔진 크롤링 | 페이지에 검색엔진 수집·링크 추적 금지(noindex, nofollow) 설정 적용, 화면에도 노출 차단 고지 문구 표시 |
| 비로그인 접근 | 로그인 없이 전체 화면 열람 가능(공개 범위가 "링크를 가진 사람 공개"인 경우) |
| 메시지 미입력 방명록 등록 | 등록되지 않고 입력창 포커스 + 안내 토스트만 표시 |
| 공개 편지 없음 | 시안에는 항상 3건이 있어 빈 상태 화면이 없다(개발 반영 시 빈 상태 문구 필요) |
| 방명록 0건 | 시안에는 항상 7건이 있어 빈 상태 화면이 없다(개발 반영 시 빈 상태 문구 필요) |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 유료 특별 헌화 도입 여부 — 계약서(F25)는 "검토 항목, 이번 범위에서 자리만 마련"으로 두었고, 이 시안은 무료 헌화(카운트 증가)만 구현했다. 실제 유료 헌화를 넣을지, 넣는다면 결제 연동 범위를 확정해야 한다.
- 무효화된 공유 링크(재발급 전 옛 링크) 접근 시 화면 — 계약서(F37)는 "차단 안내를 보여준다"고 정의했지만 이 시안에는 해당 화면이 구현되어 있지 않다. 차단 안내 문구·디자인을 별도로 확정해야 한다.
