# P8 알림·표시 설정

> URL `/mypage/notifications` · 대상 **사용자** · 관련 기능 F8, F28, F34

마이페이지에서 진입해 알림 수신 여부·채널·시간과 글자 크기를 조절하는 화면이다. 알림 항목은 반려견 상태(함께하는 중/무지개다리)에 따라 자동으로 켜고 끌 수 있는 항목이 달라지며, 글자 크기는 이 화면에서 바꾸면 앱 전체 화면에 즉시 반영된다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기(마이페이지로 이동) + 가운데 정렬 제목 "알림·표시 설정" | - |
| 무지개다리 안내 배너 | 반려견이 무지개다리 상태일 때만 노출, 기록·투약·병원·삶의 질 알림이 자동으로 꺼졌다는 안내 | F34 |
| 알림 종류 | 기록 리마인드 / 투약·병원 일정 / 삶의 질 체크 주기 / 방명록 새 글, 각각 ON/OFF 토글 | F8, F34 |
| 삶의 질 체크 주기 선택 | 삶의 질 체크 주기 행 바로 아래 들여쓴 3일마다 / 1주마다(기본) / 2주마다 드롭다운 + 도움말 | F8 |
| 기념일 알림 | 생일 / 기일(1주기 등) / 입양 기념일, 각각 ON/OFF 토글 (기본 전부 OFF) | F28 |
| 알림 받을 시간 | "매일 알려드릴 시간" 행 우측의 오전 9:00(기본) / 오후 12:00 / 오후 6:00 / 오후 9:00 드롭다운 | F8 |
| 알림 채널 | 앱 푸시(항상 켜짐, 토글 비활성) / 이메일로도 받기(선택 토글) | F8 |
| 글자 크기 | 보통(기본)/크게/아주 크게 세그먼트 버튼 + 실시간 미리보기 문구 | F8 |

## 동작 정의

### 1. 알림 종류 토글 (F8, F34)

1. 기록 리마인드·투약·병원 일정·삶의 질 체크 주기·방명록 새 글은 시안 기본값이 모두 ON이다.
2. 토글을 누르면 켜짐/꺼짐이 즉시 반영되고 "항목명을(를) 켰어요/껐어요" 토스트가 뜬다(예: "기록 리마인드를 껐어요", "투약·병원 일정을 켰어요").
3. 삶의 질 체크 주기 항목 아래에는 체크 주기 선택 드롭다운이 항상 함께 노출된다(주기 항목이 꺼져 있어도 선택창 자체는 숨겨지지 않는다).

### 2. 삶의 질 체크 주기 변경 (F8)

1. 드롭다운에서 주기(3일/1주/2주)를 바꾸면 "삶의 질 체크 주기를 OO로 바꿨어요" 토스트가 뜬다.
2. 도움말 문구로 "주기를 바꾸면 다음 체크부터 새 주기로 알려드려요"가 항상 표시된다.

### 3. 기념일 알림 (F28)

1. 섹션 상단에 "기본은 꺼져 있어요" 안내와 "이별 후에도 OO의 기념일을 기억하고 싶다면 직접 켜주세요. 켠 항목만 보내드려요." 안내 문구가 항상 노출된다.
2. 생일/기일/입양 기념일 토글은 반려견 상태(함께하는 중/무지개다리)와 무관하게 항상 조작 가능하며 잠기지 않는다.
3. 토글을 켜면 "OO을(를) 켰어요" 토스트가, 끄면 "껐어요" 토스트가 뜬다.

### 4. 알림 받을 시간 (F8)

1. 드롭다운에서 시간(오전 9:00/오후 12:00/오후 6:00/오후 9:00)을 바꾸면 "알림 받을 시간을 OO로 바꿨어요" 토스트가 뜬다.

### 5. 알림 채널 (F8)

1. 앱 푸시는 기본 채널로 항상 켜져 있으며 토글 자체가 비활성(조작 불가) 상태로 표시된다.
2. 이메일 토글을 켜면 "가입 시 등록한 이메일로 함께 보내드려요" 안내대로 이메일 채널이 추가되고, 토글 시 "OO을(를) 켰어요/껐어요" 토스트가 뜬다.

### 6. 글자 크기 (F8, 접근성)

1. 보통/크게/아주 크게 세그먼트 버튼 중 하나를 누르면 해당 값이 즉시 활성 표시되고 화면 내 미리보기 문구("오늘 OO는 어떤 하루였나요?")를 포함한 화면 전체 글자 크기가 바뀐다.
2. 선택값은 `localStorage`의 `rd-font-scale` 키에 저장된다(크게="lg", 아주 크게="xl", 보통은 키를 삭제).
3. 이 키는 이 화면에서만 쓰지 않고 다른 사용자 화면에서도 공통으로 읽어 반영한다 — 즉 여기서 글자 크기를 바꾸면 앱 내 다른 화면에 다시 들어가도 커진 글자 크기가 그대로 유지된다.
4. 페이지 진입 시 저장된 값을 읽어 선택 버튼과 글자 크기를 그 값으로 먼저 맞춘 뒤 화면을 보여준다.
5. 크기를 바꿀 때마다 "글자 크기를 OO로 바꿨어요" 토스트가 뜬다.

### 7. 반려견 상태에 따른 잠금 (F34)

1. 반려견 상태는 이 화면에 별도 전환 스위처 없이 `localStorage`의 `rd-pet-state` 값(P4·P5·P6 등에서 저장한 값)을 그대로 읽어 판단한다.
2. 상태가 "무지개다리"이면 상단에 안내 배너가 나타나고, 기록 리마인드·투약·병원 일정·삶의 질 체크 주기 3개 항목은 자동으로 꺼진 상태로 바뀌며 토글이 비활성(조작 불가)되고 각 항목 설명 문구가 "무지개다리 상태에서는 사용할 수 없어요"로 바뀐다.
3. 같은 상태에서는 삶의 질 체크 주기 드롭다운도 비활성되고 도움말 문구가 "무지개다리 상태에서는 사용할 수 없어요"로 바뀐다.
4. 방명록 새 글 알림, 기념일 알림, 알림 받을 시간, 알림 채널, 글자 크기는 무지개다리 상태에서도 잠기지 않고 그대로 조작 가능하다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 반려견 상태 = 무지개다리 | 안내 배너 노출 + 기록·투약·병원·삶의 질 항목 토글/주기 선택 잠금(비활성) |
| 반려견 상태 = 함께하는 중(기본) | 안내 배너 숨김, 모든 항목 조작 가능 |
| 앱 푸시 채널 | 항상 켜짐 고정, 토글 자체가 비활성이라 끌 수 없음 |
| localStorage 접근 실패(예외 상황) | 오류를 무시하고 기본값(함께하는 중 상태, 보통 글자 크기)으로 표시 |

## 확정 필요

- 이메일 알림 채널을 켤 때 수신할 이메일 주소를 이 화면에서 직접 확인·변경할 수 있어야 하는지(현재 시안은 "가입 시 등록한 이메일" 문구만 있고 별도 입력·표시 UI는 없음)
- 시안의 토글·드롭다운 변경은 토스트만 띄우며 실제 저장 API 호출은 없음 — 개발 반영 시 서버 저장·실패 시 롤백 처리 필요
