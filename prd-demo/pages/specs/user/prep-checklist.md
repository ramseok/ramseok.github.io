# P15 준비 체크리스트·마지막 날 플래너 (이별 준비)

> URL `/farewell/checklist` · 대상 **사용자** · 관련 기능 F15, F16

이별 준비 모드일 때만 홈(P4)의 "이별 준비" 섹션을 통해 들어오는 화면이다. 화면 안에서 **준비 체크리스트**와 **마지막 날 플래너** 두 탭을 오가며, 단계별 준비 항목을 체크·메모하거나 마지막 하루를 미리 적어 둘 수 있다. 플래너는 정서적 부담이 큰 기능이라 별도 화면 이동이나 강제 노출 없이, 사용자가 직접 탭을 눌러야만 나타난다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기(홈 이동) + 타이틀 "이별 준비" | - |
| 상단 탭 | 준비 체크리스트 / 마지막 날 플래너 2개 탭(균등 폭), 기본은 체크리스트 탭 활성, 스크롤해도 상단에 고정 | F15, F16 |
| 진행 상황 카드 | "체크리스트 진행 상황" 제목과 완료/전체 개수(시안 4 / 9)가 한 줄, 그 아래 "순서는 자유예요. 필요한 것부터 천천히 살펴보세요." 안내와 진행률 바(44%) | F15 |
| 단계별 항목 목록 | 9개 체크 카드 — 체크박스, 항목명, 메모 버튼(또는 이동 버튼) | F15 |
| 하단 안내 문구 | "항목은 필요에 따라 조금씩 바뀔 수 있어요. 정해진 순서는 없어요." | F15 |
| 플래너 안내 배너 | "마음이 준비됐을 때, 천천히 적어주세요…" | F16 |
| 플래너 입력 폼 | 보리가 좋아하는 음식 / 가고 싶은 장소 / 함께할 사람 / 그 밖에 남기고 싶은 것(메모) | F16 |
| 플래너 저장 영역 | 전체 폭 저장하기 버튼 + 버튼 아래 "방금 저장했어요" 표시 | F16 |
| 토스트 | 완료 토글·메모 저장·플래너 저장 시 하단 알림 | F15, F16 |

## 동작 정의

### 1. 탭 전환 (F15, F16)

1. 화면 진입 시 "준비 체크리스트" 탭이 기본 활성 상태로 열린다.
2. 사용자가 "마지막 날 플래너" 탭을 누르면 체크리스트 영역이 숨겨지고 플래너 영역이 나타나며, 본문 스크롤 위치가 맨 위로 초기화된다.
3. 탭 바는 본문을 스크롤해도 화면 상단에 고정되어, 스크롤한 상태에서도 바로 다른 탭으로 전환할 수 있다.
4. 플래너 탭은 홈이나 다른 화면에서 자동으로 열리거나 강제 이동되지 않으며, 오직 이 화면 안에서 사용자가 탭을 눌러야만 진입된다.

### 2. 체크리스트 진행률과 완료 토글 (F15)

1. 진입 시 시안 데이터 기준 9개 항목 중 4개가 완료 상태로 표시되어 진행 카드에 "4 / 9"와 44% 진행률 바가 표시된다.
2. 사용자가 항목의 체크박스를 누르면 해당 카드가 완료 스타일(배경색·취소선)로 바뀌고, 진행 카드의 개수와 진행률 바가 즉시 다시 계산된다.
3. 완료로 표시하면 하단 토스트에 항목명을 큰따옴표로 감싼 문구(예: "마지막 산책 다녀오기" 완료로 표시했어요)가, 완료를 취소하면 "완료 표시를 취소했어요"가 뜬다.
4. 항목 순서는 고정 목록이며 사용자가 직접 추가·삭제·재정렬하는 기능은 이 시안에 없다.

### 3. 항목별 메모 (F15)

1. "장례업체 알아보기"를 제외한 8개 항목에는 메모 버튼이 있으며, 누르면 메모 입력창이 펼쳐지고(다시 누르면 접힘) 펼쳐질 때 텍스트 영역에 포커스가 간다.
2. 이미 메모가 있는 항목(가족과 이야기하기, 장례 방식 정하기, 좋아하는 물건 정리하기)은 카드 아래 "메모: …" 미리보기가 처음부터 보이고, 입력창에도 같은 내용이 채워져 있다.
3. 저장 버튼을 누르면 입력한 내용이 "메모: …" 형태로 미리보기에 반영되고 입력창은 다시 접히며, 토스트로 "메모를 저장했어요"가 뜬다. 공백만 입력하고 저장하면 미리보기가 빈 문구로 지워진다.

### 4. 장례업체 알아보기 연결 (F15 → F18)

1. "장례업체 알아보기" 항목에는 메모 기능이 없고, 대신 "알아보기" 버튼이 있어 누르면 장례 정보 화면(P17, `funeral-info.html`)으로 이동한다.
2. 이 항목의 체크 여부는 다른 항목과 동일하게 체크박스로 별도 처리되며, 장례 정보 화면 이동과는 연동되지 않는다(자동 체크되지 않음).

### 5. 마지막 날 플래너 입력·저장 (F16)

1. 플래너 탭에는 보리가 좋아하는 음식, 가고 싶은 장소, 함께할 사람 입력란(각 한 줄 입력)과 "그 밖에 남기고 싶은 것" 여러 줄 메모란이 있으며, 시안에서는 모두 빈 값(플레이스홀더만 표시)이다.
2. "저장하기" 버튼을 누르면 입력값과 무관하게 토스트 "마지막 날 플래너를 저장했어요"가 뜨고, 버튼 아래에 "방금 저장했어요" 표시가 나타났다가 약 2.6초 후 사라진다.
3. 저장 후 다른 화면으로 자동 이동하지 않고 같은 화면에 머무른다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 새로고침·재방문 | 시안에는 저장소 연동이 없어 체크·메모·플래너 입력이 항상 초기 데이터로 되돌아간다(개발 반영 시 사용자별 저장 필요) |
| 메모 공백 저장 | 미리보기 문구가 비워지고 카드에는 아무 메모도 남지 않는다 |
| 플래너 전 필드 공백 상태로 저장 | 필수 입력 검증 없이 저장 토스트가 그대로 뜬다 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 체크리스트 완료 상태·메모, 플래너 입력값의 실제 저장 방식(사용자별 서버 저장 여부, 동기화 시점)
- "장례업체 알아보기" 버튼 클릭이 체크 완료로 자동 연동되어야 하는지 여부
- 마지막 날 플래너 데이터의 접근 권한 범위(가족 공유 구성원에게도 공개할지)
