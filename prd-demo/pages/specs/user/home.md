# P4 상태별 홈 (함께하는 중 · 이별 준비 · 무지개다리)

> URL `/home` · 대상 **사용자** · 관련 기능 F3, F6, F8, F34, F35

로그인 후 진입하는 앱의 첫 화면으로, 선택된 반려견의 상태(함께하는 중 / 이별 준비 / 무지개다리)에 따라 인사 문구·메뉴 구성이 통째로 바뀐다. 상단에는 검수·시연 전용 상태 스위처가 별도로 붙어 있어 세 상태의 홈을 한 화면에서 미리 볼 수 있고, 실제 상태 전환은 이 페이지가 아니라 반려견 관리(P5)·무지개다리 전환(P6)에서만 일어난다. 헤더의 반려견 스위처로 보리·콩이 중 누구의 홈을 볼지도 바꿀 수 있다.

## 동작 정의

### 1. 상태별 홈 전환 (F3)

1. `data-states` 속성이 붙은 각 섹션은 현재 상태 값이 포함될 때만 보이고 나머지는 숨겨지며, 상태가 바뀌면 본문 스크롤이 맨 위로 초기화된다.
2. 세 상태에서 노출되는 블록은 다음과 같다(글자 크기 설정 반영은 상태·예외 표 참조).

| 상태 | 노출되는 주요 블록 |
|------|--------------------|
| 함께하는 중 | 프로필 카드(뱃지: 함께하는 중) · 오늘의 일정 · 기록하기 퀵메뉴 · 건강 요약 · 버킷리스트 · 최근 다이어리 |
| 이별 준비 | 프로필 카드(뱃지: 이별 준비) · 이별 준비 메뉴(체크리스트·편지·장례 정보) · 오늘의 일정 · 기록하기 퀵메뉴 · 삶의 질 기록 · 버킷리스트 · 최근 다이어리 |
| 무지개다리 | 되돌리기 배너 · 추모관 대표 카드 · 추모관 메뉴 · 최근 편지 · 추억 모아보기 · 마음 돌봄 |

### 2. 시연용 상태 스위처 (실서비스 UI 아님)

1. 페이지 상단 별도 패널에서 함께하는 중/이별 준비/무지개다리 버튼을 누르면 **보리**의 홈 미리보기가 즉시 전환된다. 콩이의 홈을 보고 있던 중이면 자동으로 보리의 홈으로 돌아온 뒤 선택한 상태를 적용한다.
2. 이 값은 브라우저에 저장되어 새로고침 후에도 유지되고, URL의 `?state=` 파라미터가 있으면 저장값보다 우선 적용된다.
3. 실제 상태 전환은 이 패널이 아니라 반려견 관리(P5, 이별 준비 전환·복귀)와 무지개다리 전환(P6)에서만 이뤄진다는 안내 문구가 항상 붙어 있다.

### 3. 반려견 전환 (헤더 스위처 · 바텀시트)

1. 헤더의 반려견 이름을 누르면 보리·콩이 바텀시트가 열리고, 선택하면 헤더·인사 영역·프로필 카드의 이름·품종·성별·나이·함께한 일수가 바뀌며 시트가 닫히고 "OO의 홈을 보고 있어요" 토스트가 뜬다.
2. 콩이는 "함께하는 중" 고정이라 선택 시 함께하는 중 구성으로 전환되고, 저장된 보리의 상태 값은 덮어쓰지 않는다. 나머지 콘텐츠는 보리의 더미 데이터가 유지된다(확정 필요 참조).

### 4. 되돌리기 배너 (F6)

1. 무지개다리 상태에서만 "혹시 잘못 남기셨다면 OO월 OO일까지 이전 상태로 되돌릴 수 있어요" 배너가 노출되고, 배너의 "이전 상태로 되돌리기" 버튼은 무지개다리 전환(P6)의 되돌리기 모드로 이동한다.

### 5. 오늘의 일정 · 투약 체크 (F34)

1. "챙겼어요" 버튼을 누르면 버튼이 체크 아이콘·확정 스타일로 바뀌고 다시 누를 수 없게 비활성화되며, "관절 영양제 챙긴 것을 남겨뒀어요" 토스트가 뜬다.
2. 병원 재진 일정 항목을 누르면 건강·삶의 질 기록(P11)으로 이동한다.

### 6. 함께하고 싶은 일(버킷리스트) 토글

1. 스탬프를 누르면 카드가 완료 상태로 바뀌고 메타 문구가 "9월 29일 · 함께했어요"로 바뀌며 "함께한 일로 담아뒀어요" 토스트가 뜨고, 다시 누르면 원래 메타 문구로 되돌아간다(완료 취소).
