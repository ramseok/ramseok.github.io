# P16 미리 쓰는 편지

> URL `/farewell/letter` · 대상 **사용자** · 관련 기능 F17

이별 준비 모드의 홈(P4)에서 "이별 준비" 섹션을 통해 들어오는 화면으로, 반려동물에게 미리 편지를 써두는 공간이다. 목록에서 기존 편지를 확인하거나 새 편지를 쓰며, 편지는 기본적으로 나만 볼 수 있고 무지개다리를 건널 때 추모관에 남길지 여부만 미리 표시해 둘 수 있다. 뒤로가기는 P15(준비 체크리스트)로 돌아간다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기(작성 중엔 목록으로, 목록에서는 P15로) · 제목("미리 쓰는 편지" / "새 편지 쓰기" / "편지 수정") | F17 |
| 목록 화면 안내 배너 | 자물쇠 아이콘 + "편지는 기본적으로 나만 볼 수 있어요. 나중에 무지개다리를 건널 때, 추모관에 함께 남길지 다시 한번 여쭤볼게요" 문구 | F17 |
| 목록 화면 편지 목록 | "OO에게 쓴 편지" 제목 + 우측 "모두 {n}통", 편지 카드(편지 아이콘 · 제목과 같은 줄 우측에 작성일 · 본문 2줄 미리보기 · 게시 예정 편지는 "추모관에 남길 편지" 태그 · 우측 화살표) | F17 |
| 작성·수정 화면 안내문 | "천천히, 마음이 가는 대로 적어보세요. 언제든 다시 와서 이어 쓸 수 있어요" | F17 |
| 작성·수정 화면 입력폼 | 제목 입력란(라벨 우측 "선택" 표기, placeholder "예: 우리 보리에게") · 편지 내용 입력란(필수, placeholder "보리에게 하고 싶은 말을 적어보세요.") | F17 |
| 작성·수정 화면 게시 토글 카드 | "무지개다리를 건널 때 추모관에 남길까요?" + "지금 켜두어도 그때 다시 한번 여쭤보고 정해요. 언제든 바꿀 수 있어요." 안내 문구 + 우측 스위치 | F17 |
| 작성·수정 화면 저장 메타 | 새 편지는 "아직 저장되지 않았어요", 수정 편지는 "OO월 OO일에 저장한 편지예요" | F17 |
| 하단 고정 영역 | 목록에서는 "새 편지 쓰기" 버튼, 작성 중에는 "목록으로" · "임시저장" 버튼 | F17 |

## 동작 정의

### 1. 편지 목록 조회 (F17)

1. 화면에 진입하면 반려동물 이름이 들어간 "OO에게 쓴 편지" 목록과 총 편지 통수("모두 6통")가 표시된다.
2. 각 편지 카드는 제목·작성일·본문 미리보기 2줄을 보여주며, 제목을 비워둔 편지는 "제목 없음"으로 회색 표기된다.
3. 게시(추모관에 남기기)로 표시된 편지에는 "추모관에 남길 편지" 태그가 붙는다.
4. 편지 카드를 탭하면 해당 편지의 수정 화면으로 이동한다.

### 2. 새 편지 작성 (F17)

1. 하단 "새 편지 쓰기" 버튼을 누르면 작성 화면으로 전환되고 제목·내용·게시 토글이 빈 값으로 초기화되며 헤더 제목이 "새 편지 쓰기"로 바뀐다.
2. 제목은 선택 입력이며 비워도 저장할 수 있다.
3. 편지 내용을 입력하지 않거나 2자 미만으로 "임시저장"을 누르면 입력란이 오류 표시(빨간 테두리)되고 "편지 내용을 조금만 더 적어주세요" 문구가 나타나며 저장되지 않는다.
4. 내용이 2자 이상인 상태로 "임시저장"을 누르면 목록 맨 위에 새 편지가 추가되고, 총 통수가 1 증가하며, "보리에게 쓴 편지를 잘 담아뒀어요" 토스트와 함께 목록 화면으로 돌아간다.

### 3. 기존 편지 수정 (F17)

1. 목록에서 편지를 탭하면 해당 편지의 제목·내용·게시 여부가 입력란에 채워지고 헤더 제목이 "편지 수정"으로 바뀐다.
2. 저장 메타에는 그 편지의 작성일을 기준으로 "OO월 OO일에 저장한 편지예요"가 표시된다.
3. 내용을 수정하고 "임시저장"을 누르면 목록 내 위치는 그대로 두고 같은 편지 카드의 제목·본문·게시 태그·날짜(오늘 날짜로 갱신)가 갱신되고, 동일한 완료 토스트가 뜨며 목록으로 돌아간다.

### 4. 추모관 게시 여부 토글 (F17)

1. 작성·수정 화면의 "무지개다리를 건널 때 추모관에 남길까요?" 스위치를 켜면 저장 시 해당 편지가 게시 대상으로 표시되고 목록 카드에 "추모관에 남길 편지" 태그가 붙는다.
2. 시안에서는 토글 값이 즉시 추모관에 반영되지 않고, 편지 데이터에 게시 희망 여부만 저장해 둔다. 실제 게시는 F5 무지개다리 전환 시 다시 한번 확인을 거친 뒤 결정된다.

### 5. 화면 전환·이탈 (F17)

1. 목록 화면에서 헤더 뒤로가기를 누르면 P15(준비 체크리스트)로 이동한다.
2. 작성·수정 화면에서 헤더 뒤로가기 또는 "목록으로" 버튼을 누르면 저장 없이 목록 화면으로 돌아간다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 제목 미입력 | 목록 카드에 "제목 없음"(회색)으로 표기, 저장은 정상 처리 |
| 편지 내용 2자 미만 | 입력란 오류 강조 + "편지 내용을 조금만 더 적어주세요" 문구, 저장 차단 |
| 저장 직후 | 새 편지는 목록 최상단에 추가, 수정 편지는 기존 위치에서 갱신, "보리에게 쓴 편지를 잘 담아뒀어요" 토스트 3초 노출 |
| 신규 편지의 저장 메타 | "아직 저장되지 않았어요" 문구, 저장 후 목록으로 이동하며 사라짐 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 시안은 목록·편지 데이터가 하드코딩(6통)되어 있고 임시저장 시 브라우저 세션에만 반영된다. 개발 반영 시 실제 사용자별 편지 저장·불러오기 및 반려동물별 다건 관리 방식 확정 필요
- 게시 토글 값이 F5(무지개다리 전환) 시 어떤 문구·화면으로 재확인되는지는 P16 시안에는 없고 F5 쪽 기획에서 확정 필요
