# P26 마이페이지

> URL `/mypage` · 대상 **사용자** · 관련 기능 F1

로그인한 보호자 김서연의 계정 정보와 앱 전반의 관리 메뉴를 모아둔 화면이다. 프로필 확인·수정, 반려견·가족 관리, 설정, 구독·데이터, 고객 지원으로 진입하는 진입점 역할을 하며, 화면 맨 아래에서 로그아웃과 회원 탈퇴를 처리한다. 하단 탭바 5개 중 "마이" 탭에서 항상 진입할 수 있다.

---

| 영역 | 내용 | 관련 기능 |

## 동작 정의

### 1. 프로필 정보 수정 (F1)

1. 프로필 카드의 연필 아이콘을 누르면 이름·이메일 입력 필드가 담긴 바텀시트가 열린다.
2. 시안의 초기값은 이름 "김서연", 이메일 "boribori0602@example.com"이다.
3. "저장하기"를 누르면 입력값이 프로필 카드의 이름("OO 님")·이메일에 즉시 반영되고 바텀시트가 닫히며 "프로필 정보를 저장했어요" 토스트가 뜬다.
4. 입력값을 비우고 저장하면 원래 기본값(김서연 / boribori0602@example.com)으로 되돌아간다.
5. 바텀시트 바깥 딤 영역을 누르면 저장 없이 닫힌다.

### 2. 메뉴 리스트 이동 (F2, F7, F8, F31, F32, F33, F38)

1. 반려견·가족, 설정, 구독·데이터, 고객 지원 각 그룹의 리스트 항목을 누르면 해당 하위 화면(반려견 관리 P5, 가족 공유 P7, 알림·표시 설정 P8, 구독·결제·데이터 내보내기 P24, 1:1 문의 P25)으로 이동한다.
2. 구독·결제와 데이터 내보내기 두 항목은 시안에서 동일한 파일(account-billing.html)로 연결된다.
3. 각 리스트 항목의 보조 문구(등록 마릿수·구성원 수·알림 설정 요약·용량·답변 대기 건수)는 더미 데이터로 고정 표기되며, 하위 화면에서의 실제 변경이 이 화면에 반영되지는 않는다.

### 3. 로그아웃 (F1)

1. "로그아웃" 버튼을 누르면 "로그아웃하고 있어요" 토스트가 뜨고, 잠시 후 로그인 화면(P2)으로 이동한다.
2. 시안에는 로그아웃 확인 모달 없이 즉시 처리된다.

### 4. 회원 탈퇴 (F1)

1. "회원 탈퇴" 텍스트 링크를 누르면 확인 모달이 열린다.
2. 모달에는 "탈퇴하면 보리·콩이의 기록, 사진, 편지, 추모관이 모두 사라지고 되돌릴 수 없어요"라는 즉시 삭제 안내와 데이터 내보내기(P24) 링크가 함께 노출된다.
3. "기록이 모두 사라진다는 것을 알고 있어요" 체크박스에 동의해야 "탈퇴할게요" 버튼이 활성화된다.
4. 체크 해제 시 탈퇴 버튼은 다시 비활성화된다.
5. "잠시 후에 할게요"를 누르면 모달이 닫히고 체크 상태도 초기화된다.
6. "탈퇴할게요"를 누르면 "탈퇴 처리를 하고 있어요" 토스트가 뜨고, 잠시 후 로그인 화면(P2)으로 이동한다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 무료 플랜 태그 | 시안은 "무료 플랜" 고정 표기, 실제 구독 상태 연동은 개발 반영 시 필요 |
| 글자 크기 저장값(lg/xl) 있음 | 알림·표시 설정에서 저장된 값이 화면 전체 글자 크기에 반영된다 |
| 회원 탈퇴 동의 미체크 상태로 진입 | 매번 모달을 열 때 체크박스는 해제, 탈퇴 버튼은 비활성 상태로 시작한다 |

## 확정 필요

- 회원 탈퇴 시 데이터 처리 정책 — 계약서(01_FEAT.md)에는 탈퇴 처리 방식이 명시되어 있지 않다. 시안 모달 문구는 "탈퇴하면 …모두 사라지고 되돌릴 수 없어요"로 **즉시 삭제**를 안내하고 있으나, 실제 개발에서는 즉시 삭제와 일정 기간 유예 보관(복구 가능 기간을 둔 뒤 삭제) 중 어느 정책을 적용할지 고객사 확정이 필요하다.
