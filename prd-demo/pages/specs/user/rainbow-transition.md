# P6 무지개다리 전환

> URL `/rainbow/transition` · 대상 **사용자** · 관련 기능 F5, F6, F35

반려견이 무지개다리를 건넜을 때 이별일과 안내 여부를 입력하고 2단계 확인을 거쳐 상태를 전환하는 화면이다. 전환이 끝나면 알림 정리·추모관 생성·홈 전환이 한 번에 처리된다. 같은 화면에서 `?mode=revert`로 들어오면 전환 후 7일 이내에 이전 상태로 되돌리는 흐름(5~6단계)으로 바로 진입한다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기 버튼(단계별 이동) + 단계 제목("무지개다리 전환" / "전환 완료" / "이전 상태로 되돌리기") | F5, F6 |
| 진행 표시 | 헤더 아래 무지개 띠 진행 트랙(단계만큼 채워짐: 1단계 약 1/3, 2단계 약 2/3, 3단계 전체) + 트랙 우측 "n / 3" 텍스트, "n / 3" 텍스트는 1~3단계에서만 노출되고 4단계 이후 숨김 | F5 |
| STEP1 | 상단 안내 배너("이 화면은 OO와의 이별을 기록하는 곳이에요…") + 이별일(필수, * 표시) · 남기고 싶은 한마디(라벨 우측 "선택" 표시) 입력 + "안내 선택" 섹션 토글 2개(가족에게 안내하기 / 보내기 전 편지 게시하기) | F5 |
| STEP2 | "이 내용으로 남길까요?" 제목 + 입력값 요약 카드(이별일·남기고 싶은 한마디·가족 안내·편지 게시, 한마디는 라벨 아래 전체 폭으로 표시) | F5 |
| STEP3 | 처리 예정 목록(알림 중지·추모관 생성·홈 전환 + 조건부 가족/편지 안내) · 7일 이내 되돌리기 안내 · 동의 체크박스 | F5 |
| STEP4 | 전환 완료 결과 목록(체크 표시) · 되돌리기 기한 안내 · "공간으로 가기"/"메모리얼 페이지 바로 열기" CTA | F5, F35 |
| STEP5 | 되돌리기 확인 요약 카드(남긴 이별일·되돌릴 상태·기한) + 되돌리면 벌어질 일 목록 | F6 |
| STEP6 | 되돌리기 완료 결과 목록(체크 표시) · "홈으로 가기" CTA | F6 |

## 동작 정의

### 1. 전환 입력 (1~4단계) (F5)

1. 이별일을 입력하지 않으면 STEP1의 "다음" 버튼이 비활성 상태로 유지된다.
2. "가족에게 안내하기" 토글을 켜면 이후 단계에서 "언니 은지님에게 소식을 전할게요" 항목이 노출된다.
3. "보내기 전 편지 게시하기" 토글을 켜면 이후 단계에서 "써둔 편지를 추모관에 게시할게요" 항목이 노출된다.
4. "다음"을 누르면 입력한 이별일·한마디·안내 선택 결과가 STEP2 요약 카드에 그대로 반영되고, 한마디를 비워두면 "남기지 않았어요"로 표시된다.
5. STEP2에서 "잠시 후에 할게요"를 누르면 STEP1로 돌아가고, "네, 기록할게요"를 누르면 STEP3로 이동한다.
6. STEP3에는 알림 중지·추모관 생성·홈 전환이 기본으로 표시되고, 가족 안내/편지 게시를 켠 경우에만 해당 항목이 추가로 표시된다.
7. STEP3의 동의 체크박스("위 내용을 확인했으며, 지금 전환할게요")를 체크해야 "전환 완료하기" 버튼이 활성화되며, 옆의 "이전" 버튼을 누르면 STEP2로 돌아간다.
8. "전환 완료하기"를 누르면 반려견 상태가 무지개다리(RAINBOW)로 저장되고, 전환 직전 상태(함께하는 중/이별 준비)가 되돌리기용으로 별도 저장된다.
9. 되돌리기 가능 기한은 입력한 이별일로부터 7일 뒤로 자동 계산되어 STEP4 안내 문구("혹시 잘못 남기셨다면 OO까지 이전 상태로 되돌릴 수 있어요")에 표시된다.
10. STEP4에서는 STEP3에서 예고한 항목들이 체크 표시와 함께 완료 문구("멈췄어요/만들었어요/바뀌었어요")로 다시 노출된다.
11. STEP4 하단에는 "OO의 공간으로 가기"(home.html)와 "메모리얼 페이지 바로 열기"(memorial-edit.html) 두 개의 CTA가 있다.

### 2. 되돌리기 (5~6단계) (F6)

1. URL에 `?mode=revert`가 있으면 1~4단계를 건너뛰고 STEP5부터 시작한다.
2. STEP5 요약 카드에는 남긴 이별일, 되돌릴 상태(전환 직전 상태 라벨), 되돌릴 수 있는 기한이 표시된다. 이별일 "9월 24일 (목)"과 기한 "10월 1일 (목)까지"는 시안 고정값이다(실제 전환 기록과 연동되지 않음).
3. 되돌릴 상태 라벨은 전환 시 저장해둔 직전 상태값을 읽어 "함께하는 중" 또는 "이별 준비"로 표시하고, 저장된 값이 없으면 "이별 준비"로 처리한다.
4. STEP5의 목록에는 "홈 화면이 [직전 상태] 상태로 돌아가요" · "추모관은 비공개로 보관돼요" · "지금까지 남긴 기록은 그대로 있어요" 세 항목이 안내된다.
5. STEP5에서 "그대로 둘게요"를 누르면 되돌리지 않고 home.html로 이동한다.
6. "이전 상태로 되돌리기"를 누르면 반려견 상태가 직전 상태로 복원되고 STEP6(완료 화면)로 이동한다.
7. STEP6에는 "홈 화면을 [직전 상태] 상태로 바꿨어요" · "추모관은 비공개로 보관돼요" 두 항목이 체크 표시와 함께 노출되고, 하단에 "홈으로 가기" CTA가 있다.

### 3. 공통 동작

1. 반려견 이름은 `?pet=` 쿼리 값으로 치환되며, 값이 없으면 기본값 "보리"가 쓰인다.
2. 뒤로가기 버튼은 STEP1과 STEP5에서는 home.html로 이동하고, 그 외 단계에서는 바로 이전 단계로 이동한다.
3. STEP4·STEP6에서는 뒤로가기 버튼 자체가 숨겨진다(자리는 유지되어 헤더 제목 위치는 그대로).
4. 헤더 아래 진행 트랙의 무지개 띠는 1단계 약 1/3, 2단계 약 2/3, 3단계 전체 폭으로 채워지며, 우측 "n / 3" 텍스트가 함께 바뀐다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 이별일 미입력 | STEP1 "다음" 버튼 비활성 |
| STEP3 동의 미체크 | "전환 완료하기" 버튼 비활성 |
| 가족 안내 토글 off | STEP3·STEP4 목록에서 가족 관련 항목 숨김 |
| 편지 게시 토글 off | STEP3·STEP4 목록에서 편지 관련 항목 숨김 |
| 직전 상태값 없음(신규 등록 직후 전환 등) | 되돌릴 상태를 기본값 "이별 준비"로 표시 |
| 저장소(localStorage) 접근 실패 | 시안에서는 오류를 무시하고 화면 흐름은 그대로 진행(실제 저장은 되지 않음) |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 되돌리기 완료 후 알림(기록·투약·병원·삶의 질 체크) 재개 여부 — 시안 스크립트는 상태값만 복원할 뿐, 전환 시 중지했던 알림을 다시 켜는 처리는 정의돼 있지 않다.
- 이미 생성된 추모관의 실제 처리 방식 — 시안 문구는 "추모관은 비공개로 보관돼요"로만 되어 있고, 데이터 삭제·완전 비공개 전환·재전환 시 재사용 여부는 명세에 없다.
- STEP4의 "메모리얼 페이지 바로 열기" 노출 조건(전체 보호자 공통 노출인지, 가족 공유 편집 권한자에 한정되는지) 확정 필요.
