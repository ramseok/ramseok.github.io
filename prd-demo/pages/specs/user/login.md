# P2 로그인 (로그인 · 회원가입 탭)

> URL `/login` · 대상 **사용자** · 관련 기능 F1

가입 여부에 따라 로그인 또는 회원가입을 하나의 화면에서 처리하는 진입 화면이다. 이메일 로그인·소셜 로그인(카카오·네이버·애플·구글)을 모두 제공하며, 비밀번호 재설정은 별도 페이지 없이 바텀시트로 처리한다. 최초 가입자는 반려견 등록(P3)으로, 기존 회원은 상태별 홈(P4)으로 이동한다. 가족 공유 초대 링크(`?invite`)로 들어온 경우에는 로그인·가입 완료 후 가족 공유 화면(P7)으로 이동한다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 브랜드 영역 | 서비스 로고(아바타 아이콘)·서비스명·소개 문구 | - |
| 초대 배너 | 초대 링크로 진입했을 때만 노출. 병원명·반려견 이름을 포함한 안내 문구 | F1 |
| 탭 | 로그인 / 회원가입 전환 | F1 |
| 로그인 패널 | 이메일·비밀번호 입력, 비밀번호 표시 토글, 비밀번호 찾기, 로그인 버튼, 소셜 로그인 4종, 회원가입 전환 링크 | F1 |
| 회원가입 패널 | 이름·이메일·비밀번호·비밀번호 확인 입력, 약관 동의 체크박스, 가입하기 버튼, 소셜 로그인 4종, 로그인 전환 링크 | F1 |
| 비밀번호 재설정 바텀시트 | 이메일 입력 후 재설정 링크 발송 | F1 |
| 토스트 | 로그인 중·가입 확인 중·재설정 링크 발송 완료 메시지 | - |

## 동작 정의

### 1. 초대 링크 진입 (F1)

1. URL에 `invite` 쿼리 파라미터가 있으면 화면 상단에 초대 배너("OO님이 [반려견 이름]의 가족 공유에 초대했어요")가 노출된다. 파라미터가 없으면 배너는 숨김 처리된다.
2. 초대 링크로 진입한 상태에서 로그인 또는 회원가입을 완료하면 홈(P4)이 아니라 가족 공유(P7)로 이동한다.

### 2. 탭 전환 (F1)

1. 상단 "로그인" / "회원가입" 탭을 누르면 해당 패널만 보이고 나머지는 숨겨지며, 본문 스크롤이 맨 위로 초기화된다.
2. 로그인 패널 하단 "회원가입" 링크, 회원가입 패널 하단 "로그인" 링크를 눌러도 같은 방식으로 탭이 전환된다.

### 3. 로그인 (F1)

1. 이메일·비밀번호 입력란은 각각 봉투·자물쇠 아이콘을 좌측에 두고, 비밀번호 입력란 우측의 눈 모양 버튼을 누르면 비밀번호 표시/숨김이 토글된다.
2. "로그인" 버튼을 누르면 "로그인하고 있어요" 토스트가 뜬 뒤 0.3초 후 다음 화면으로 이동한다. 시안에서는 이메일·비밀번호 값 검증 없이 항상 이동한다.
3. 이동 목적지는 초대 진입 여부에 따라 상태별 홈(P4) 또는 가족 공유(P7)로 갈린다.

### 4. 회원가입 (F1)

1. 이름·이메일·비밀번호·비밀번호 확인 4개 입력란을 채운다. 비밀번호 입력란에도 표시/숨김 토글이 있다.
2. "(필수) 이용약관 및 개인정보 처리방침에 동의해요" 체크박스를 체크해야만 "가입하기" 버튼이 활성화된다. 체크 해제 시 버튼은 다시 비활성화된다.
3. "가입하기" 버튼(활성 상태)을 누르면 "가입 정보를 확인하고 있어요" 토스트가 뜬 뒤 0.3초 후 다음 화면으로 이동한다. 시안에서는 이름·이메일·비밀번호 형식이나 비밀번호 일치 여부는 검증하지 않는다.
4. 이동 목적지는 초대 진입 여부에 따라 반려견 등록(P3) 또는 가족 공유(P7)로 갈린다.

### 5. 소셜 로그인 (F1)

1. 카카오·네이버·애플·구글 4개 버튼 중 하나를 누르면 현재 활성 탭을 기준으로 즉시 이동한다.
2. 로그인 탭에서 누르면 로그인과 동일한 목적지(P4 또는 P7)로, 회원가입 탭에서 누르면 회원가입과 동일한 목적지(P3 또는 P7)로 이동한다. 토스트나 지연 없이 바로 이동한다.

### 6. 비밀번호 재설정 (F1)

1. 로그인 패널의 "비밀번호를 잊으셨나요?" 버튼을 누르면 바텀시트가 열린다.
2. 바텀시트에는 이메일 입력란과 "재설정 링크 보내기" 버튼이 있다.
3. 버튼을 누르면 시트가 닫히고 "재설정 링크를 보내드렸어요" 토스트가 뜬다. 시안에서는 이메일 값 검증 없이 항상 성공 처리한다.
4. 시트 바깥 딤(dim) 영역을 누르면 값 검증 없이 시트가 닫힌다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 초대 파라미터 없음 | 초대 배너 미노출, 로그인·가입 완료 시 각각 P4·P3로 이동 |
| 약관 미동의 상태에서 가입 버튼 클릭 | 버튼이 비활성화되어 있어 클릭이 무시된다 |
| 페이지 재진입 | 저장된 글자 크기 설정(`rd-font-scale`)이 있으면 화면에 반영된다 |

## 확정 필요

- 로그인·가입 버튼의 입력값 검증(이메일 형식, 빈 값, 비밀번호 일치, 중복 이메일 등)이 시안에는 없다 — 개발 반영 시 실패 케이스(에러 메시지·버튼 비활성 등) 정의 필요
- 비밀번호 재설정 이메일이 실제 가입 이메일인지 확인하는 로직, 미가입 이메일 입력 시 처리 방식 확정 필요
- 소셜 로그인 실제 연동 시 최초 로그인(신규 가입) vs 기존 회원 여부를 서버에서 판별하는 방식 확정 필요
