# P3 온보딩: 반려견 등록

> URL `/onboarding/pet` · 대상 **사용자** · 관련 기능 F2

최초 가입 직후(P2 로그인 다음) 딱 한 번 거치는 화면이다. 뒤로가기 없이 제목만 있는 헤더로 "이 단계는 꼭 거쳐야 한다"는 흐름을 만들고, 이름·생년월일만 있으면 바로 기록을 시작할 수 있다는 안내로 부담을 낮춘다. 필수 항목(이름·생년월일 또는 추정 나이)만 검증하고, 나머지 선택 항목을 입력하지 않아도 등록 후 상태별 홈(P4)으로 넘어간다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기 없이 "반려견 등록" 제목만 표시(최초 온보딩 전용) | F2 |
| 안내 문구 | "마지막 준비예요" 캡션 + "우리 아이를 소개해주세요" 타이틀 + 보조 설명 | F2 |
| 대표 사진 | 원형 업로드 버튼(선택), 누르면 담은 상태로 토글 | F2 |
| 이름 | 필수 입력, 최대 12자, 미입력 시 인라인 에러 | F2 |
| 생년월일 / 추정 나이 | 기본은 생년월일 입력(필수). "생일을 모르겠어요" 링크로 추정 나이 입력으로 전환 가능(이 경우 추정 나이가 필수) | F2 |
| 함께한 날 미리보기 | 생년월일 입력 시 "함께한 지 ○일이에요" 안내 배너 자동 노출 | F2 |
| 견종 | 선택 입력 텍스트 필드 | F2 |
| 성별 | 선택, 남아/여아 세그먼트 단일 선택(재클릭 시 해제) | F2 |
| 입양일 | 선택 입력, 날짜 필드 | F2 |
| 동물등록번호 | 선택 입력, 숫자 15자리, 입력 중 마스킹 미리보기 표시 | F2 |
| 안내 문구 | "등록하면 '함께하는 중' 상태로 시작하며 이후 마이페이지에서 바꿀 수 있다"는 디스클레이머 | F2 |
| 하단 CTA | "등록하고 시작하기" 버튼(탭바 없는 플로우 페이지) | F2 |

## 동작 정의

### 1. 대표 사진 등록 (F2)

1. 사진 버튼을 누르면 담은 상태(체크 아이콘 + 강조 테두리)로 바뀌고, 버튼 아래 문구가 "대표 사진을 담았어요"로 바뀌며 "사진을 담았어요" 토스트가 뜬다.
2. 담은 상태에서 다시 누르면 카메라 아이콘·"대표 사진 (선택)" 문구로 되돌아간다.
3. 시안에서는 실제 파일 업로드 없이 버튼 상태 토글로만 사진 선택을 시뮬레이션한다.

### 2. 이름·생년월일 입력 (F2)

1. 이름은 필수이며 최대 12자까지 입력한다.
2. 생년월일 입력칸의 날짜 상한은 오늘(2026-09-29)이다.
3. 생년월일을 입력하면 오늘 기준 함께한 일수를 계산해 "함께한 지 ○일이에요" 배너가 자동으로 나타난다.
4. "생일을 모르겠어요"를 누르면 생년월일 입력이 숨겨지고 추정 나이 입력(정수, 0~30)으로 바뀌며, 라벨이 "추정 나이*"로, 도움말이 "정확한 날짜를 몰라도 괜찮아요. 대략적인 나이만 알려주세요."로 바뀐다. 이때 함께한 날 배너는 숨겨진다.
5. 추정 나이 모드에서 "생년월일을 알아요"를 다시 누르면 생년월일 입력 모드로 되돌아가고, 반대쪽 입력값은 초기화된다.

### 3. 선택 항목 (F2)

1. 견종·성별·입양일·동물등록번호는 모두 선택 입력이며(라벨 우측에 "선택" 표시) 비워도 등록에 지장이 없다.
2. 성별은 남아/여아 중 하나만 선택되며, 선택된 버튼을 다시 누르면 선택이 해제된다.
3. 동물등록번호는 숫자만 15자리까지 입력받는다. 9자리 미만이면 "등록 후 일부만" 문구를 유지하고, 9자리 이상 입력되면 앞 4자리 + 가운데 마스킹(*) + 뒤 4자리 형태로 실시간 미리보기가 바뀐다.
4. 입양일 입력칸의 날짜 상한도 오늘(2026-09-29)이다.

### 4. 등록 완료 (F2)

1. "등록하고 시작하기"를 누르면 이름과 생년월일(또는 추정 나이) 필수값을 검증한다.
2. 필수값이 비어 있으면 처음 발견된 에러 필드로 자동 스크롤하고 "필수 항목을 다시 확인해주세요" 토스트를 띄운다. 화면 전환은 일어나지 않는다.
3. 필수값이 모두 채워져 있으면 "{이름}의 프로필이 준비됐어요" 토스트가 뜨고, 약 0.7초 뒤 상태별 홈(P4, `home.html`)으로 자동 이동한다.
4. 시안에서 등록된 반려견의 상태 기본값은 "함께하는 중"으로 고정 표시된다(화면 내 실제 저장 로직은 없음).

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 이름 미입력 후 등록 시도 | 이름 필드에 "이름을 알려주세요" 에러 문구 표시, 첫 에러 필드로 스크롤 |
| 생년월일·추정 나이 모두 미입력 후 등록 시도 | 생년월일 영역에 "생년월일 또는 추정 나이 중 하나는 꼭 알려주세요" 에러 문구 표시 |
| 추정 나이 0 또는 음수 입력 | 유효하지 않은 값으로 처리되어 등록 시 에러 표시 |
| 동물등록번호 7자리 미만 입력 | 마스킹 미리보기 문구가 "등록 후 일부만"으로 유지됨 |
| 생년월일에 미래 날짜 입력 시도 | 입력칸 자체의 max 속성(2026-09-29)으로 선택 제한 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 대표 사진은 시안에서 실제 업로드 없이 버튼 상태 토글로만 시뮬레이션된다 — 개발 반영 시 카메라 권한 요청·이미지 리사이즈(F36) 연동 플로우 확정 필요
- 등록 완료 시 실제 계정에 반려견 프로필을 저장하는 로직(F2 저장 API 연동)은 시안에 없고 홈 이동만 구현되어 있다
- "오늘" 기준일(2026-09-29)은 시연용 고정값이며, 개발 반영 시 실제 시스템 날짜로 대체되어야 한다
