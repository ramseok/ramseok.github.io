# P12 소리·발도장 보관함

> URL `/keepsake` · 대상 **사용자** · 관련 기능 F12, F36

보리(반려견)의 짖는 소리·숨소리를 녹음하고 발도장 사진을 모아두는 화면이다. 화면 순서는 소개 → 녹음하기 → 녹음 목록 → 발도장 사진 → 발도장·털 보관 가이드 → 타임라인 이동이며, 홈(P4)에서 진입하고 하단에서 추억 타임라인(P13)으로 이어진다. 탭바가 없는 기록 상세 화면이라 뒤로가기로만 나간다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 헤더 | 뒤로가기 + "소리·발도장 보관함" 타이틀 (탭바 없음) | - |
| 소개 카드 | 발자국 아이콘 + "보리의 소리와 발자국을 남겨요" 문구 | F12 |
| 녹음하기 | 원형 마이크 비주얼 · 00:00 타이머 · "건당 최대 3분까지 녹음할 수 있어요" 안내 · "녹음 시작/정지" 버튼 | F12, F36 |
| 녹음 목록 | 보관 중인 녹음 7건(더미) — 좌측 원형 재생 버튼, 이름·길이·날짜, 우측 삭제 아이콘, 진행 막대는 재생 중에만 노출, 원본 백업 안내 문구 | F12, F36 |
| 발도장 사진 | 3열 그리드, 사진 4장(더미) + "사진 추가" 타일, 고화질 별도 보관 안내 문구 | F12, F36 |
| 발도장·털 보관 가이드 | 아코디언 4항목(CMS 콘텐츠) | F12 |
| 하단 이동 | "타임라인에서 모아보기" 버튼 → P13 | P13 진입 경로 |

## 동작 정의

### 1. 소리 녹음하기 (F12, F36)

1. "녹음 시작" 버튼을 누르면 마이크 비주얼이 붉게 펄스 애니메이션되고 버튼이 "정지"(위험 색상)로 바뀌며 1초 단위 타이머가 올라간다.
2. 녹음 중에는 안내 문구가 "녹음하고 있어요"로 바뀐다.
3. 녹음 시간은 **건당 최대 3분(180초)**까지만 가능하며, 3분에 도달하면 자동으로 정지되고 "3분이 다 돼서 자동으로 저장했어요" 토스트가 뜬다.
4. 사용자가 직접 "정지"를 눌러 멈추면 "소리가 잘 보관됐어요" 토스트가 뜨고, 녹음 목록 맨 위에 "새로운 녹음"이라는 이름으로 새 항목이 추가된다.
5. 정지 후 타이머는 00:00으로, 버튼은 "녹음 시작"으로, 비주얼은 원래 색으로 되돌아온다.
6. 시안에서는 실제 마이크 권한 요청·오디오 저장 없이 타이머와 목록 추가만 시뮬레이션한다. 개발 반영 시 실제 마이크 권한 획득과 오디오 파일 업로드가 필요하다.

### 2. 녹음 목록 관리 (F12, F36)

1. 목록에는 더미 녹음 7건이 이름·길이·날짜와 함께 나열되며, 상단에 "N개 보관 중" 개수가 실시간으로 표시된다.
2. 진행 막대는 평소에는 보이지 않고 재생 중인 항목의 이름·길이 아래에만 나타난다. 재생 버튼을 누르면 아이콘이 일시정지로 바뀌고, 항목이 옅은 강조 배경으로 표시되며, 진행 막대가 나타나 해당 녹음 길이만큼 채워진다. 다른 항목을 재생하면 재생 중이던 항목은 자동으로 멈춘다.
3. 재생 중인 항목의 재생 버튼을 다시 누르거나 녹음 길이만큼 재생이 끝나면 정지되고, 진행 막대가 초기화되어 다시 숨겨진다.
4. 이름 영역(재생 버튼 제외)을 누르면 프롬프트 창이 뜨고, 새 이름을 입력해 확인하면 이름이 바뀐다. 빈 값이거나 취소하면 이름은 변경되지 않는다.
5. 삭제 아이콘을 누르면 확인 없이 즉시 목록에서 제거되고 "녹음을 지웠어요" 토스트가 뜨며 개수가 갱신된다. 재생 중이던 항목을 삭제하면 재생도 함께 멈춘다.
6. "녹음 파일은 원본 그대로 안전하게 백업돼요" 문구로 F36(이중 백업)을 안내한다.

### 3. 발도장 사진 (F12, F36)

1. 사진 그리드는 더미 이미지 4장과 "사진 추가" 타일로 구성되고, 상단에 "N장 보관 중" 개수가 표시된다.
2. "사진 추가" 타일을 누르면 실제 파일 선택 없이 새 더미 사진 타일이 그리드에 즉시 추가되고, "발도장 사진이 추가됐어요" 토스트가 뜨며 개수가 올라간다. 시안 시뮬레이션이며 개발 반영 시 실제 이미지 업로드·리사이즈·원본 보관(F36)이 필요하다.
3. "원본 사진은 고화질로 별도 보관돼요" 문구로 원본 백업 정책을 안내한다.

### 4. 발도장·털 보관 가이드 (F12)

1. 가이드는 아코디언 4항목(캐스팅 뜨는 법 / 털 보관법 / 녹음 파일 보관 안내 / 잉크 vs 점토 비교)으로 구성되며 CMS 콘텐츠로 운영진이 관리한다.
2. 항목을 누르면 해당 항목만 펼쳐지거나 접히며 화살표 아이콘이 180도 회전한다. 여러 항목을 동시에 펼칠 수 있다(다른 항목이 자동으로 닫히지 않음).

### 5. 타임라인 이동

1. 하단 "타임라인에서 모아보기" 버튼을 누르면 추억 타임라인(P13)으로 이동한다.
2. 녹음(및 발도장 사진)은 타임라인과 추모관 녹음 섹션에도 함께 반영되는 것이 기획 의도이나, 이 시안 화면 자체에는 그 반영 결과가 표시되지 않는다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 녹음 0초 만에 정지 | 목록에 추가되지 않고 토스트도 뜨지 않는다(0초 녹음 무시) |
| 녹음 3분 초과 도달 | 자동 정지 + "3분이 다 돼서 자동으로 저장했어요" 토스트 |
| 이름 바꾸기 입력값 없음/취소 | 기존 이름 유지, 토스트 없음 |
| 녹음 목록·사진 모두 삭제해 0건이 됨 | 시안에는 빈 상태 문구가 별도로 없다(개발 반영 시 빈 상태 UI 확정 필요) |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 녹음·사진을 0건까지 지웠을 때 보여줄 빈 상태 문구·일러스트가 시안에 없다
- 발도장 사진 삭제 기능이 시안에 없다(추가만 가능) — 개발 범위에 삭제도 포함할지 확인 필요
- 실제 마이크 권한 거부 시 안내 문구(권한 요청 실패 케이스)가 시안에 없다
