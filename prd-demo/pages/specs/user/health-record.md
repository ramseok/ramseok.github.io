# P11 건강·삶의 질 기록

> URL `/health` · 대상 **사용자** · 관련 기능 F10, F11

보리(반려견)의 일상 건강 지표와 삶의 질 점수를 기록·확인하는 화면이다. 상단 내부 탭으로 "건강 기록"과 "삶의 질 체크"를 전환하며, 두 탭 모두 본문 맨 위(내부 탭 위)에 면책 문구가 상시 노출된다. 사용자는 이 화면에서 오늘 상태를 훑어보고(요약·추이 그래프), 과거 기록을 목록으로 확인하고, `+` 버튼으로 새 기록을 추가한다.

---

## 동작 정의

### 1. 내부 탭 전환 (F10, F11)

1. 사용자가 "건강 기록" 탭을 누르면 건강 기록 패널이 보이고 "삶의 질 체크" 탭이 비활성화된다.
2. 사용자가 "삶의 질 체크" 탭을 누르면 삶의 질 패널이 보이고, 본문 스크롤 위치가 맨 위로 초기화된다.
3. 면책 문구는 두 탭 어디서나 본문 맨 위(내부 탭 위)에 노출되며 탭 전환으로 사라지지 않는다.
4. 본문을 아래로 스크롤하면 면책 문구는 함께 스크롤되어 올라가고, 내부 탭(건강 기록/삶의 질 체크)은 본문 상단에 고정되어 계속 보인다.

### 2. 건강 기록 — 오늘 요약·추이 (F10)

1. 오늘 요약 카드는 가장 최근 기록 기준(시안 9월 23일)으로 체중·식사·음수·배변·투약·다음 병원 방문 6개 지표를 보여준다.
2. 체중 추이 그래프는 기본값이 "주간"이며, 사용자가 "월간"을 누르면 그래프 선, 기간 표기("최근 7주" → "최근 4개월"), x축 라벨("7주 전·4주 전·이번 주" → "4개월 전·2개월 전·이번 달")이 월간 데이터로 즉시 바뀐다(끝점 위치와 최신 체중 3.4kg은 두 기간 동일).
3. 최근 기록 목록의 항목(체중/식사/음수/배변/투약/병원 방문)을 누르면 해당 기록 내용을 요약한 토스트가 3초간 노출된다.

### 3. 삶의 질 체크 — 조회 (F11)

1. 삶의 질 탭 상단에는 "점수로 상태를 판단하거나 예측하지 않아요" 안내 배너가 항상 노출된다.
2. 최근 결과 카드는 가장 최근 체크(시안 9월 20일) 기준 6개 항목 점수와 메모를 보여준다.
3. 좋은 날 비율 추이 그래프 아래에는 "지난 기록보다 좋은 날이 조금 줄었어요. 담당 수의사와 상담해 보세요" 문구가 상시 노출되며, 점수 자체에 대한 좋음/나쁨 판정 문구는 어디에도 표시하지 않는다.
4. 최근 체크 기록 목록의 항목을 누르면 해당 기록 요약 토스트가 노출된다.

### 4. 삶의 질 체크 — 오늘 체크하기 (F11)

1. 통증·식욕·수분·위생·행복감·움직임 6개 항목은 1~5점 중 하나를, 좋은 날 비율은 1~7일 중 하나를 칩으로 선택한다. 각 그룹은 단일 선택만 허용되며 시안은 각 항목에 기본 선택값이 미리 지정돼 있다.
2. 메모 입력란은 선택 항목이며 시안에는 예시 문구가 기본으로 채워져 있다.
3. "오늘 기록 저장하기"를 누르면 "오늘의 기록을 담아뒀어요" 토스트가 노출된다. 시안에서는 실제 저장·목록 반영은 이루어지지 않는다.

### 5. 기록 추가 바텀시트 (F10)

1. 헤더의 `+` 버튼을 누르면 하단에서 바텀시트가 올라오고, 바깥 어두운 영역(딤)을 누르면 닫힌다.
2. 시트 상단 칩(체중/식사/음수/배변/투약/병원)을 선택하면 해당 유형의 입력 폼만 보이고 나머지는 숨겨진다. 기본 선택은 "체중"이다.
3. 식사량/음수량/배변 상태는 세그먼트 버튼으로 3단계 중 하나를 단일 선택한다.
4. "병원" 유형에서 "영수증 사진 추가" 버튼을 누르면 버튼 라벨이 "영수증 추가됨"으로 바뀌고 "영수증 사진을 담았어요" 토스트가 노출된다. 시안에서는 실제 사진 업로드는 이루어지지 않는다.
5. "저장하기"를 누르면 바텀시트가 닫히고 "오늘의 기록을 저장했어요" 토스트가 노출된다. 시안에서는 실제 저장·추이 그래프·목록 반영은 이루어지지 않는다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 면책 문구 노출 | 두 탭 공통으로 내부 탭 위에 항상 표시, 탭 전환으로도 사라지지 않음 |
| 삶의 질 점수 하락 | 판정 문구 없이 "담당 수의사와 상담해 보세요" 안내만 제공 |
| 기록 추가 폼 저장 | 시안은 토스트 피드백만 있고 실제 데이터 반영·유효성 검증은 없음 |
| 투약 알림·병원 재방문 알림 등록(F34 연동) | 이 시안 화면에는 알림 등록 UI가 없음 |
| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |

## 확정 필요

- 삶의 질 체크 문항(통증·식욕·수분·위생·행복감·움직임·좋은 날 비율)과 점수 척도는 계약서상 "자문 확정 문항"으로 명시되어 있어, 수의학 자문 결과에 따라 문항 구성·표현이 변경될 수 있다. 개발 착수 전 자문 확정본으로 최종 반영 여부를 확인해야 한다.
- 점수 하락 시 상담 안내 문구를 띄우는 기준(임계값·연속 횟수 등)은 시안에 고정 텍스트로만 구현돼 있어 실제 로직 기준을 확정해야 한다.
