# P14 버킷리스트

> URL `/bucket-list` · 대상 **사용자** · 관련 기능 F14 (F13과 연계)

보리와 함께 하고 싶은 일을 추천 항목 또는 직접 입력으로 담아두고, 완료하면 사진·메모로 인증하는 화면이다. 완료 인증은 타임라인(P13)에 자동으로 쌓이는 것을 전제로 한다. 사용자는 상단 필터로 진행 중/완료 항목을 나눠 보고, 완료한 항목은 다시 진행 중으로 되돌릴 수도 있다.

## 동작 정의

### 1. 추천 항목 담기 (F14)

1. 추천 항목 칩 4개 중 하나를 누르면 해당 항목이 "내가 담은 일" 목록 맨 위에 진행 중 카드로 추가된다.
2. 담긴 칩은 즉시 비활성화(체크 아이콘 표시)되어 같은 항목을 중복으로 담을 수 없다.
3. 담기와 동시에 토스트 "목록에 담았어요"가 표시되고 목록 개수가 1 증가한다.
4. 추천 항목 중 "단골 가게에 마지막으로 들르기"는 체력 부담 주의 항목으로, 담기면 카드 메타 문구가 "컨디션을 먼저 확인하세요"로 표시된다.

### 2. 직접 추가 (F14)

1. 헤더 + 버튼을 누르면 "어떤 일을 함께 하고 싶나요?" 바텀시트가 열린다.
2. 입력값 없이 "목록에 담기"를 누르면 입력칸이 에러 상태(빨간 테두리 + "하고 싶은 일을 적어주세요")가 되고 저장되지 않는다.
3. 값을 입력하고 저장하면 목록 맨 위에 진행 중 카드로 추가되고("직접 추가한 항목" 메타 표기) 바텀시트가 닫히며 토스트 "목록에 담았어요"가 뜬다.

### 3. 완료 처리 (F14, F13)

1. 진행 중 카드의 스탬프 버튼을 누르면 완료 인증 바텀시트("{항목명}, 함께 해냈어요")가 열린다.
2. 사진 첨부 버튼을 누르면 아이콘이 "사진 담았어요" 상태로 토글되며(시안에서는 실제 업로드 없이 상태만 토글), 다시 누르면 원상태로 돌아간다.
3. 메모를 입력하지 않고 "타임라인에 담기"를 눌러도 저장은 가능하며, 이 경우 메타 문구는 기본값 "함께한 일로 남겨뒀어요"로 채워진다.
4. 저장하면 카드가 완료 상태(배경색 강조 + 채워진 스탬프)로 바뀌고, 메타 문구가 "9월 29일 · (메모 또는 기본 문구)"로 갱신되며 토스트 "타임라인에 담아뒀어요"가 뜬다.
5. 완료 처리는 타임라인(P13)에 자동 등록되는 것을 전제로 한다(개발 반영 시 실제 연동 확인 필요).

### 4. 완료 취소 (F14)

1. 완료 카드의 스탬프를 다시 누르면 확인 절차 없이 즉시 진행 중 상태로 되돌아간다.
2. 메타 문구는 주의 항목이면 "컨디션을 먼저 확인하세요", 직접 추가 항목이면 "직접 추가한 항목", 추천 항목이면 "추천 항목"으로 복원된다.

### 5. 상태 필터 (F14)

1. 전체 / 진행 중 / 완료 탭 중 하나를 누르면 해당 상태의 카드만 목록에 남고 나머지는 숨김 처리된다.
2. 필터를 바꿔도 상단 "내가 담은 일" 개수 표시는 전체 개수를 그대로 유지한다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 담긴 항목 0개 | 목록 대신 빈 상태 아이콘 + "아직 담긴 일이 없어요" 노출 |
| 직접 추가 입력값 공백 | 입력 필드 에러 스타일 + 안내 문구, 바텀시트 유지 |
| 이미 담은 추천 칩 재클릭 | 칩이 비활성화되어 있어 클릭이 동작하지 않음 |

| 글자 크기 저장값(lg/xl) 있음 | P8에서 고른 크기로 화면 전체 글자 확대 |
