# P33 제휴 업체 관리

> URL `/admin/partners` · 대상 **관리자** · 관련 기능 F43

관리자가 장묘업체·상담기관·인쇄 업체 정보를 등록·수정하고, 사용자 화면(장례 정보 P17 등)에 노출할지를 관리하는 화면이다. 특히 장묘업체는 관할 기관 정식 등록 여부와 검증일을 함께 관리하며, 정식 등록이 확인되지 않은 곳은 사용자 화면에 절대 노출되지 않도록 시스템이 강제한다. 대시보드(P28)에서 진입한다.

---

## 동작 정의

### 1. 업체 유형 탭·검색·지역 필터 (F43)

1. 진입 시 "전체" 탭이 활성화되어 장묘업체 10곳·상담기관 4곳·인쇄 업체 3곳, 총 17곳이 모두 보인다.
2. 장묘업체/상담기관/인쇄 업체 탭을 누르면 해당 유형의 행만 남고 탭별 건수 배지가 패널 부제의 "총 N곳"과 별개로 항상 표시된다.
3. 업체명 검색창에 입력하면 이름에 검색어가 포함된 행만 남고, 지역 셀렉트를 바꾸면 해당 지역 문자열이 포함된 행만 남는다. 탭·검색·지역 조건은 동시에 적용된다.
4. 결과 건수 캡션이 "N개 업체"로 실시간 갱신된다.
5. 비용 범위가 " · "로 이어진 여러 항목이면 첫 항목만 본 줄에, 나머지는 아래 보조 줄에 두 줄로 표시된다(예: 상담기관 "마음이음 펫로스상담센터"는 "회당 6만원" / "초기 상담 무료"). 항목이 하나면 한 줄로 표시된다.
6. 헤더의 "필터 초기화" 버튼을 누르면 탭이 "전체"로, 검색어와 지역이 빈 값으로 복귀하고 "필터를 초기화했어요" 토스트가 뜬다.

### 2. 정식 등록·검증일 관리 — 장묘업체 전용 (F43)

1. 장묘업체 행에는 "정식 등록"/"미등록" 태그와 검증일이 표시되고, 상담기관·인쇄 업체 행은 두 칸 모두 "해당 없음"으로 고정된다.
2. 미등록 장묘업체는 검증일 칸에 "심사 대기"만 표시되고 "검증일 갱신" 버튼 자체가 나타나지 않는다.
3. 등록된 장묘업체는 검증일을 "YYYY.MM.DD" 형식으로 보여주고, 오늘(2026.09.29) 기준 경과일이 150일 이상이면 "임박", 180일 이상이면 "만료됨" 상태 배지가 함께 붙는다. 그 미만이면 "정상"으로 별도 강조 없이 표시된다.
4. "검증일 갱신" 버튼을 누르면 확인 절차 없이 즉시 해당 업체의 검증일이 오늘 날짜로 바뀌고 "OO의 검증일을 오늘 날짜로 갱신했어요" 토스트가 뜬다.
5. 등록된 장묘업체 중 검증 상태가 "정상"이 아닌 곳이 하나라도 있으면 목록 상단에 "재검증이 필요한 장묘업체가 N곳 있어요" 배너가 뜨고, 모두 정상이면 배너가 숨겨진다. 현재 더미 데이터 기준 대상은 1곳("무지개숲 펫스톤", 검증일 2026-03-01 → 만료됨)이다.

### 3. 사용자 화면 노출 토글 — 미등록 장묘업체 노출 차단 (F43, P17 연동)

1. 상담기관·인쇄 업체와 정식 등록이 확인된 장묘업체는 노출 토글을 자유롭게 켜고 끌 수 있고, 토글 옆에 "노출중"/"비노출" 캡션이 실시간으로 바뀐다.
2. 토글을 바꾸면 "OO 노출을 시작했어요"/"OO 노출을 껐어요" 토스트가 뜬다.
3. **정식 등록이 확인되지 않은 장묘업체는 노출 토글 자체가 비활성화(disabled)되어 조작할 수 없고**, 토글 옆에 "정식 등록 확인 후 노출 가능" 안내 캡션이 항상 붙는다. 이 규칙은 미등록 업체가 우연히라도 켜져 있지 않도록 데이터 구조상 `exposed` 값과 무관하게 표시를 강제한다.
4. 사용자 화면의 장례 정보(P17, F18)에 노출되는 장묘업체 목록은 이 화면에서 "정식 등록" + "노출" 두 조건을 모두 만족한 곳만 반영된다는 전제다. 현재 더미 데이터의 노출중 장묘업체 8곳이 P17에 그대로 대응한다.

### 4. 업체 등록·수정 모달 (F43)

1. 헤더 우상단의 "업체 등록" 버튼을 누르면 빈 모달이 뜨고, 업체 유형 기본값은 현재 활성 탭과 같은 유형(전체 탭이면 장묘업체)으로 지정된다.
2. 업체 유형을 "장묘업체"로 두면 "관할 기관 정식 등록" 토글과 "검증일" 입력 필드가 나타나고, "확인일로부터 150일이 지나면 재검증 안내가 표시돼요" 도움말이 붙는다. 다른 유형을 고르면 이 두 필드가 숨겨진다.
3. 업체명·지역·연락처는 필수값이며, 비워둔 채 저장을 누르면 각 입력칸에 빨간 테두리와 "OO을 입력해 주세요" 오류 문구가 표시되고 저장이 진행되지 않는다.
4. 업체 유형이 장묘업체이고 "정식 등록" 토글이 꺼진 상태에서 "사용자 화면 노출" 토글이 켜져 있으면, 저장 시 "정식 등록 확인 후 노출할 수 있어요…" 토스트만 뜨고 저장이 차단된다 — 노출을 끄거나 정식 등록을 먼저 켜야 저장된다.
5. 저장에 성공하면 신규 등록은 "OO 업체를 등록했어요", 기존 수정은 "OO 정보를 수정했어요" 토스트가 뜨고 모달이 닫히며 목록·탭 건수·재검증 배너가 모두 다시 계산된다.
6. 행의 "수정" 버튼을 누르면 해당 업체의 기존 값이 모달에 채워진 채로 열리고, "취소" 버튼이나 모달 바깥(딤 영역) 클릭으로 저장 없이 닫을 수 있다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 미등록 장묘업체의 노출 토글 클릭 시도 | 토글이 disabled라 조작 자체가 불가하며, 혹시 변경 이벤트가 발생해도 강제로 꺼지고 "정식 등록이 확인된 장묘업체만 노출할 수 있어요" 토스트가 뜬다 |
| 검증일 경과 150일 이상 | 검증일 배지가 "임박"으로 바뀌고 재검증 배너 대상에 포함된다 |
| 검증일 경과 180일 이상 | 검증일 배지가 "만료됨"으로 바뀌고 재검증 배너 대상에 포함된다 |
| 등록·수정 모달 필수값 누락 | 저장 버튼을 눌러도 해당 필드에 오류 표시만 뜨고 모달이 닫히지 않는다 |
| 미등록 장묘업체 + 노출 켠 채로 저장 시도 | 저장이 차단되고 안내 토스트만 노출된다 |
| 검색/지역 필터로 결과가 0건 | 표가 빈 채로 남고 "0개 업체" 캡션만 갱신된다(별도 빈 상태 일러스트는 없음) |

## 확정 필요

- 검증 유효기간 기준(150일 임박·180일 만료)이 실제 관할 기관 재검증 주기와 일치하는지, 지역·업체별로 기준이 달라질 수 있는지
- "정식 등록" 확인 자체를 서류·행정 조회로 검증하는 절차가 별도로 있는지, 있다면 그 결과를 이 화면에 어떻게 반영할지(첨부파일·심사 이력 등)
- 등록 취소(정식 등록 해제) 시 이미 노출 중이던 업체를 즉시 자동으로 비노출 처리할지, 관리자 확인 절차를 추가할지
