# P32 신고·모더레이션 (무지개 일기(가칭))

> URL `/admin/reports` · 대상 **관리자** · 관련 기능 F42

운영 매니저가 방명록·커뮤니티에서 접수된 신고를 검토하고 숨김·삭제·제재·반려 중 하나로 처리하는 화면이다. 상단에 신고 목록(대기·처리완료·반려)을 출처·상태로 필터링해 보여주고, 신고 건을 열면 상세 모달에서 원문과 이전 처리 이력을 확인한 뒤 처리 유형과 사유를 남겨 확정한다. 하단에는 처리 완료된 건들의 이력이 최신순으로 쌓인다.

---

## 동작 정의

### 1. 신고 목록 조회·필터 (F42)

1. 화면 진입 시 더미 신고 12건(대기 5 · 처리완료 5 · 반려 2)이 접수일시 최신순으로 표시되고, 상단 요약 문구가 각 건수를 보여준다.
2. 출처 세그먼트(전체·방명록·커뮤니티)를 선택하면 해당 출처의 신고만 표에 남는다.
3. 상태 세그먼트(전체·대기·처리완료·반려)를 선택하면 해당 상태의 신고만 표에 남는다. 출처·상태 필터는 동시에 적용된다.
4. 필터 조건에 맞는 신고가 없으면 표 대신 "조건에 맞는 신고가 없어요" 안내가 표시된다.
5. 필터를 바꿔도 상단 요약 문구(대기/처리완료/반려 전체 건수)는 필터와 무관하게 전체 기준으로 유지된다.
6. 신고 대상 열의 텍스트가 길면 말줄임(ellipsis) 처리되고, 마우스 오버 시 title 속성으로 전체 텍스트를 볼 수 있다.

### 2. 신고 상세 확인 (F42)

1. 표의 "상세" 버튼을 누르면 신고 상세 모달이 열린다.
2. 모달에는 출처 태그, 현재 상태 태그, 접수일시, 신고 대상명, 작성자(비회원 포함), 신고된 원문 내용이 표시된다.
3. 신고 사유, 신고자(마스킹 표기), 해당 대상의 누적 신고 건수가 한 줄로 표시된다.
4. 같은 신고 대상(target 문자열이 동일)에 대해 이미 처리된 이전 이력이 있으면 처리일시·처리 유형·사유가 목록으로 표시되고, 없으면 "이전 처리 이력이 없어요"가 표시된다.
5. 이미 처리된 건을 다시 열면 처리 유형 세그먼트에 기존 선택했던 유형이 활성 표시되고, 사유 입력란에도 기존 메모가 채워진다.
6. 닫기 아이콘, "취소" 버튼, 모달 바깥(dim 영역) 클릭 시 모달이 닫히고 입력 내용은 저장되지 않는다.

### 3. 신고 처리 (F42)

1. 처리 유형 세그먼트(숨김·삭제·제재·반려) 중 하나를 선택하면 해당 버튼만 활성 표시된다.
2. 처리 유형을 선택하지 않고 "처리 완료" 버튼을 누르면 "처리 유형을 먼저 선택해주세요" 토스트가 뜨고 처리되지 않는다.
3. 처리 유형을 선택한 뒤 "처리 완료"를 누르면 해당 신고의 상태가 "반려" 선택 시 반려로, 그 외(숨김·삭제·제재)는 처리완료로 바뀌고, 처리일시(오늘 날짜 기준 현재 시각)·처리자("김하늘")가 기록된다.
4. 처리 사유 입력란에 적은 내용이 처리 이력의 "사유·메모"로 저장된다. 비워두면 이력에 "-"로 표시된다.
5. 처리가 완료되면 모달이 닫히고 신고 목록·처리 이력 표가 즉시 갱신되며, 반려 시 "신고를 반려 처리했어요", 그 외에는 "신고를 처리했어요 · [처리 유형]" 토스트가 뜬다.
6. 처리 완료 시 사이드바의 대기 건수 배지와 신고 목록 상단 요약의 대기 건수가 함께 줄어든다.

### 4. 처리 이력 (F42)

1. 처리 이력 패널에는 상태가 "대기"가 아닌 모든 건(처리완료·반려)이 처리 순서 최신순으로 표시된다.
2. 화면 안에서 새로 처리한 건은 처리 이력 목록 맨 위에 추가된다.
3. 처리 유형 열의 태그는 숨김이 노랑 계열, 삭제·제재가 강조색, 반려가 테두리만 있는 중립 태그로 구분된다.
4. 처리 이력이 없으면 "처리 이력이 없어요" 안내가 표시된다. 시안 더미 데이터로는 항상 7건 이상 존재해 실제로는 발생하지 않는다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 필터 조건에 맞는 신고 없음 | 표 대신 "조건에 맞는 신고가 없어요" 안내 (colspan 7) |
| 처리 이력 없음 | 표 대신 "처리 이력이 없어요" 안내 (colspan 5, 시안 데이터로는 미발생) |
| 처리 유형 미선택 후 처리 완료 클릭 | 토스트 "처리 유형을 먼저 선택해주세요" + 모달 유지, 상태 변경 없음 |
| 같은 대상 이전 처리 이력 없음 | 모달 하단에 "이전 처리 이력이 없어요" 표시 |
| 신고 원문이 긴 경우 | 신고 대상 열은 말줄임 처리, 상세 모달 원문 영역은 전체 텍스트 노출 |

## 확정 필요

- 시안에는 제재 처리 시 기간·수위 옵션이 없고 자유 텍스트 사유 입력란만 있다. 제재 단계(예: 경고 → 7일 정지 → 30일 정지 → 영구정지 등)와 각 단계의 정지 기간 기준을 확정해야 실제 제재 로직(자동 계정 잠금·해제일 계산)을 반영할 수 있다.
- 동일 작성자가 반복 제재 대상이 될 경우 자동으로 상위 단계로 올릴지, 매번 관리자가 수동으로 판단할지 확인 필요.
- "누적 신고" 건수의 집계 기준(같은 게시물 대상 누적인지, 같은 작성자 전체 누적인지) 확인 필요.
- 반려 처리된 신고자에게 반려 사유가 통보되는지(알림 발송 여부) 확인 필요 — 시안에는 통보 관련 UI 없음.
