# P31 콘텐츠 관리(CMS)

> URL `/admin/content` · 대상 **관리자** · 관련 기능 F41

운영 매니저가 준비 체크리스트·가이드·아티클·버킷리스트 추천·삶의 질 문항·행정 안내 콘텐츠를 한 화면에서 유형별로 조회·등록·수정하고, 게시 여부를 즉시 켜고 끄는 관리 화면이다. 특히 "행정 안내" 콘텐츠는 법령 점검일을 기록해 개정 여부를 정기적으로 확인하도록 안내한다. 대시보드(P28)에서 진입하며 사이드바를 통해 다시 대시보드로 돌아갈 수 있다.

## 동작 정의

### 1. 유형별 탭 필터링 (F41)

1. 유형 탭(전체/체크리스트/가이드/아티클/버킷리스트 추천/삶의 질 문항/행정 안내)을 누르면 목록이 해당 유형만 남도록 필터링되고 클릭한 탭에 활성 스타일이 적용된다.
2. 진입 시 기본값은 "전체"이며, 각 탭 옆 숫자는 시안 더미 데이터 기준 건수다.
3. 시안 데이터는 체크리스트 1건, 가이드 3건, 아티클 2건, 버킷리스트 추천 3건, 삶의 질 문항 1건, 행정 안내 2건으로 총 12건이 고정되어 있다.

### 2. 제목 검색 (F41)

1. 검색창에 문자열을 입력하면 제목에 해당 문자열이 포함된 콘텐츠만 즉시 필터링되며, 현재 선택된 유형 탭 조건과 함께(AND) 적용된다.
2. 결과 건수는 목록 우측 상단 "N건" 표기가 실시간으로 갱신된다.
3. 조건에 맞는 콘텐츠가 없으면 표 대신 빈 상태(검색 아이콘 + "조건에 맞는 콘텐츠가 없어요")가 표시된다.

### 3. 목록 표시·게시 여부 토글 (F41)

1. 각 행은 제목, 본문 앞 28자 요약("…" 포함), 유형 태그, 게시 여부 스위치, 법령 점검일, 수정일, 편집 버튼을 보여준다.
2. 버킷리스트 추천 항목은 제목 아래 요약 줄에서 요약 뒤에 "· 체력 부담 낮음/보통/높음" 캡션이 추가로 붙는다.
3. 각 행의 편집 버튼은 연필 아이콘과 "편집" 텍스트로 표시된다.
4. 목록에서 게시 여부 스위치를 직접 켜거나 끄면 모달을 열지 않고 즉시 상태가 바뀌며, "OO(제목) 콘텐츠를 게시했어요" 또는 "OO 콘텐츠를 숨겼어요" 토스트가 뜬다.
5. 모달의 게시 여부 항목에는 "숨기면 사용자 화면에서 즉시 보이지 않아요"라는 설명이 붙어 있으나, 실제 사용자 화면 반영 여부는 이 시안 화면에서 확인할 수 없다.

### 4. 법령 점검일 표시·경과 경고 (F41)

1. 분류가 "행정 안내"인 콘텐츠만 법령 점검일이 존재하며, 그 외 유형은 목록에 "—"로 표시된다. 점검일은 "2026.06.20"처럼 YYYY.MM.DD 형식으로 표기된다.
2. 시연 오늘(2026-09-29) 기준 점검일로부터 90일 이상 지나면 날짜 앞에 경고 삼각형 아이콘이 붙고 날짜 텍스트가 강조색(빨강)·굵은 글씨로 바뀐다.
3. 시안 데이터의 행정 안내 2건 — "반려동물 등록 말소 신청 방법"(점검일 2026.06.20)과 "사망신고 후 처리해야 할 행정 절차"(점검일 2026.05.15) — 은 둘 다 90일을 넘겨 경과 표시로 나타난다.
4. 편집 모달의 법령 점검일 입력란 아래에는 "관련 법령·행정 절차 개정 여부를 점검한 날짜예요. 90일이 지나면 대시보드 처리할 일에 표시돼요."라는 안내 문구가 붙어, 대시보드(P28)의 할 일 목록과 연동됨을 시사한다(대시보드 쪽 실제 표기는 이 화면 범위 밖).

### 5. 콘텐츠 등록·편집 (F41)

1. 상단 "새 콘텐츠 등록" 버튼을 누르면 모달(제목 "새 콘텐츠 등록", 부제 "카테고리를 선택하고 본문을 작성하세요")이 열리고 제목·본문은 비어 있으며 분류 기본값 "가이드", 게시 여부는 꺼짐 상태로 시작한다.
2. 목록의 "편집" 버튼을 누르면 해당 콘텐츠의 제목·분류·본문·게시 여부·체력 부담(버킷)·법령 점검일(행정 안내)이 모달에 그대로 채워진다.
3. 분류를 "버킷리스트 추천"으로 바꾸면 체력 부담 선택란이, "행정 안내"로 바꾸면 법령 점검일 입력란이 나타나고, 그 외 분류를 선택하면 두 필드 모두 숨겨진다.
4. 제목을 비운 채 저장을 누르면 "제목을 입력해 주세요" 토스트가 뜨고 저장이 진행되지 않는다.
5. 저장을 누르면 버튼 문구가 "저장 중…"으로 바뀌며 비활성화되고, 약 0.4초 후 모달이 닫히며 목록에 반영된다. 신규 등록 시 "새 콘텐츠를 등록했어요", 기존 편집 시 "콘텐츠를 저장했어요" 토스트가 뜬다.
6. 신규 등록된 콘텐츠는 목록 맨 위에 추가되고 수정일은 시연 오늘 날짜(09.29)로 기록된다.
7. 취소(보조 버튼) 또는 모달 바깥 영역을 클릭하면 입력 내용을 저장하지 않고 모달만 닫힌다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 검색·필터 결과 없음 | 빈 상태(검색 아이콘) + "조건에 맞는 콘텐츠가 없어요" |
| 제목 미입력 저장 시도 | "제목을 입력해 주세요" 토스트, 모달 유지·저장 취소 |
| 법령 점검일 미입력(행정 안내 신규 등록) | 목록에 "—" 표시, 경과 경고 없음 |
| 법령 점검일 90일 경과 | 경고 삼각형 아이콘 + 강조색·굵은 글씨로 표시 |
| 페이지네이션 클릭 | 시안 데이터는 12건 고정 1페이지라 버튼 활성 스타일만 바뀌고 목록 내용은 변화 없음 |

## 확정 필요

- 게시 여부를 끄면 사용자 화면(F12·F19·F20 등)에 실제로 즉시 반영되는지, 캐시·배포 지연 여부
- 법령 점검일 90일 경과 시 대시보드(P28) 할 일 목록에 표시되는 정확한 문구·집계 방식
- 콘텐츠 삭제 기능 필요 여부 — 기능 목록(F41)에는 "삭제"가 포함되어 있으나 이 시안에는 삭제 버튼이 없고 등록·수정·게시 토글만 존재
- 페이지네이션이 실제 데이터량 증가 시 몇 건 단위로 나뉘는지
