# P27 관리자 로그인

> URL `/admin/login` · 대상 **관리자** · 관련 기능 - (전제, 계약서 외 — "관리자 접근 권한 분리")

운영 관리자만 접근하는 단독 로그인 화면이다. 사이드바 없이 카드 하나로 구성되며, 아이디·비밀번호를 입력해 로그인에 성공하면 대시보드(P28)로 이동한다. 이 페이지는 F# 계약 기능이 아니라 관리자 화면 전체의 진입 전제로 정의되어 있다.

---

## 화면 구성

| 영역 | 내용 | 관련 기능 |
|------|------|-----------|
| 브랜드 영역 | 무지개 아이콘·서비스명 "무지개 일기 관리자"·안내 문구 "운영 계정으로 로그인해 주세요" | - |
| 오류 알림 배너 | 로그인 실패 시에만 노출. "아이디 또는 비밀번호가 올바르지 않아요. 다시 확인해 주세요." | - |
| 로그인 카드 | 관리자 아이디 입력란(필수), 비밀번호 입력란(필수, 표시/숨김 토글), 로그인 상태 유지 체크박스, 로그인 버튼 | - |
| 하단 안내 문구 | "운영 관리자 전용 페이지예요. 계정 문의는 시스템 담당자에게 연락해 주세요." | - |
| 토스트 | 로그인 처리 중·실패 안내 메시지 | - |

## 동작 정의

### 1. 데모 계정 로그인 (시안 한정)

1. 시안에서는 아이디 `admin`, 비밀번호 `admin1234`로만 로그인이 성공 처리된다. 실제 계정 인증은 개발 반영 시 서버에서 처리한다.
2. 아이디·비밀번호를 모두 채우고 "로그인" 버튼을 누르면 값이 데모 계정과 일치하는지 시안 내에서 즉시 비교한다.
3. 일치하면 "로그인하고 있어요" 토스트가 뜨고 0.3초 후 대시보드(P28)로 이동한다.

### 2. 입력 검증

1. 아이디 또는 비밀번호 입력란을 비운 채 "로그인" 버튼을 누르면 해당 입력란 아래에 "아이디를 입력해주세요." / "비밀번호를 입력해주세요." 오류 문구가 표시되고, 오류 배너는 뜨지 않으며 화면이 이동하지 않는다.
2. 오류 상태의 입력란에 값을 입력하기 시작하면(input 이벤트) 해당 입력란의 오류 표시와 상단 오류 배너가 즉시 사라진다.

### 3. 로그인 실패 처리

1. 아이디·비밀번호를 모두 입력했지만 데모 계정 값과 다르면 상단에 오류 배너("아이디 또는 비밀번호가 올바르지 않아요. 다시 확인해 주세요.")가 노출되고, 비밀번호 입력란에 오류 표시가 붙는다.
2. 동시에 "로그인 정보를 다시 확인해주세요" 토스트가 뜬다. 화면 이동은 일어나지 않는다.

### 4. 비밀번호 표시 토글

1. 비밀번호 입력란 우측 눈 모양 버튼을 누르면 입력값이 평문으로 보이고 아이콘이 눈-감김(eye-off)으로 바뀐다.
2. 다시 누르면 마스킹(점) 표시로 되돌아가고 아이콘도 원래(eye)로 바뀐다.

### 5. 로그인 상태 유지

1. "로그인 상태 유지" 체크박스는 시안에서 체크 상태만 토글되며, 로그인 처리나 이동 로직에는 영향을 주지 않는다.

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 아이디·비밀번호 모두 공백 | 두 입력란 모두 오류 문구 표시, 오류 배너는 미노출, 이동 없음 |
| 데모 계정 불일치 | 오류 배너 노출 + 비밀번호란 오류 표시 + 실패 토스트, 이동 없음 |
| 데모 계정 일치 | 성공 토스트 → 0.3초 후 대시보드(P28)로 이동 |
| 재입력 시작 | 이전 오류 표시(입력란·배너)가 즉시 초기화 |

## 확정 필요

- 실제 관리자 계정 인증 방식(아이디/비밀번호 저장·해싱, 2차 인증 여부)이 시안에는 없다 — 개발 반영 시 확정 필요
- "로그인 상태 유지" 체크 시 세션 유지 기간·방식(쿠키/토큰 만료)이 시안에는 정의되어 있지 않다 — 개발 반영 시 확정 필요
- 관리자 계정 발급·권한 등급(슈퍼관리자/운영자 등) 분리 여부는 이 화면 시안에 없다 — 확정 필요
