# P30 1:1 문의 관리

> URL `/admin/inquiries` · 대상 **관리자** · 관련 기능 F40 (사용자 측 F33과 연동)

운영 매니저가 사용자가 남긴 1:1 문의를 한 화면에서 확인하고 답변을 등록·수정하는 화면이다. 왼쪽 목록에서 문의를 고르면 오른쪽 상세 패널에 문의 내용과 답변 작성란이 함께 뜨는 좌-목록/우-상세 구조이며, 상태(대기/답변완료) 필터와 제목·작성자 검색으로 목록을 좁힐 수 있다.

## 동작 정의

### 1. 문의 목록 조회 · 필터 · 검색 (F40)

1. 화면 진입 시 더미 문의 12건(번호 1~12, 최신순)이 테이블에 그대로 나열된다.
2. 상태 필터 세그먼트에서 "대기"를 누르면 상태가 대기인 문의만, "답변완료"를 누르면 완료된 문의만 남고, "전체"를 누르면 다시 12건이 모두 보인다.
3. 툴바 오른쪽 검색창에 문자를 입력하면 제목 또는 작성자(마스킹 표기)에 해당 문자열이 포함된 행만 실시간으로 남으며, 상태 필터와 동시에 적용(AND 조건)된다.
4. 필터·검색 결과가 0건이면 목록 영역에 "조건에 맞는 문의가 없어요" 안내가 표시된다.
5. 세그먼트 버튼과 총 건수 라벨의 숫자(전체/대기/답변완료)는 데이터 상태 변화(답변 등록 등) 즉시 재계산되어 갱신된다.
6. 새로고침 버튼을 누르면 "문의 목록을 새로고침했어요" 토스트만 뜨고, 시안 범위에서는 더미 데이터가 실제로 재조회되지는 않는다.

### 2. 문의 상세 확인 (F40)

1. 목록의 행을 클릭하면 해당 행에 선택 배경색이 적용되고, 오른쪽 상세 패널에 그 문의의 유형·상태·번호·제목·작성자·등록일·문의 내용이 표시된다.
2. 문의에 첨부파일이 있는 경우에만 문의 내용 아래에 첨부파일명 태그(클립 아이콘)가 추가로 노출된다.
3. 상태가 "답변완료"인 문의를 선택하면 문의 내용 아래에 "등록된 답변" 박스가 추가로 나타나 기존 답변 전문을 보여준다.
4. 선택된 문의가 없는 경우(초기값은 항상 첫 문의가 선택되어 있어 시안에서는 실질적으로 발생하지 않음) 상세 패널에 "왼쪽 목록에서 문의를 선택해 주세요" 빈 상태가 표시된다.

### 3. 답변 등록 · 수정 (F40)

1. 답변 작성란은 대기 상태 문의에서는 빈 텍스트영역과 "답변 등록" 버튼을, 답변완료 문의에서는 기존 답변이 채워진 텍스트영역과 "답변 수정 저장" 버튼을 보여준다.
2. 텍스트영역을 비운 채(공백만 입력해도 동일) 버튼을 누르면 "답변 내용을 입력해 주세요" 토스트가 뜨고 상태는 바뀌지 않는다.
3. 내용을 입력하고 버튼을 누르면 해당 문의의 상태가 "답변완료"로 바뀌고, 목록·상세·모든 건수 라벨이 즉시 갱신된다.
4. 원래 "대기"였던 문의를 처음 답변하면 "답변을 등록했어요" 토스트가, 이미 "답변완료"였던 문의를 다시 저장하면 "답변을 수정했어요" 토스트가 뜬다.

| 새로고침 버튼 | 토스트만 노출되고 실제 서버 재조회는 시안 범위 밖 |

## 확정 필요

- 사이드바 "1:1 문의" 메뉴의 "대기 7" 배지는 시안에서 정적 텍스트라 답변을 등록해도 줄지 않는다(헤더의 "답변 대기 N건"은 실시간 반영). 개발 시 실시간 동기화 필요.
- 답변 등록·수정, 새로고침이 모두 브라우저 메모리상 더미 데이터만 갱신하며 새로고침(F5)하면 초기 12건으로 되돌아간다. 실제 저장·서버 연동은 개발 단계에서 확정 필요.
