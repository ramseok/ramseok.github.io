# P28 대시보드(통계)

> URL `/admin/dashboard` · 대상 **관리자** · 관련 기능 F44

관리자가 로그인 후 가장 먼저 보는 화면으로, 무지개 일기 서비스의 가입자·반려견 상태·기록 작성·결제 현황을 한 화면에서 조회한다. 상단 기간 세그먼트(7일/30일/90일)로 전체 지표가 일괄 갱신되고, KPI 카드 바로 아래 가로 4칸으로 놓인 "처리할 일" 카드에서 문의·신고·제휴업체·CMS 등 다른 관리 화면(P29~P33)으로 바로 이동한다.

## 동작 정의

### 1. 기간 세그먼트 전환 (F44)

1. 7일/30일/90일 버튼을 누르면 해당 버튼이 활성 표시되고, 헤더 크럼의 기간 라벨과 가입자 추이 부제(일/주/월 단위)가 함께 바뀐다.
2. KPI 4개 카드(신규 가입자·이전 대비·기간 내 신규 반려견·기록 작성 수·이전 대비·결제액·결제 실패 건수)와 가입자 추이 막대 그래프, 결제 미니 지표 4개, 기록 작성 수 표(부제 "유형별 · 최근 N일" 포함)가 선택한 기간의 더미 데이터로 한 번에 갱신된다.
3. 등록 반려견 누적 수(21,093마리)와 상태별 반려견 스택바·목록, 결제 내역 표는 기간을 바꿔도 값이 바뀌지 않는다(시안에서는 현재 시점 고정 데이터로 처리).
4. 페이지 최초 진입 시 30일 기간이 기본 선택되어 있다.

### 2. 새로고침 · CSV 내보내기 (F44)

1. 새로고침 버튼을 누르면 상단 갱신 시각이 현재 시각(9월 29일 HH:MM 기준)으로 바뀌고 "최신 통계로 새로고침했어요" 토스트가 뜬다.
2. 새로고침을 눌러도 카드·표·그래프의 수치 자체는 다시 계산되지 않는다(시안에서는 시각 표기만 갱신).
3. CSV 내보내기 버튼을 누르면 실제 파일 다운로드 없이 "최근 N일 통계 CSV를 내려받았어요" 토스트만 뜬다(N은 현재 선택된 기간).

### 3. 상태별 반려견 수 · 회원 관리 이동

1. "회원 관리" 버튼을 누르면 회원·반려견 관리(P29)로 이동한다.
2. 무지개다리 전환 후 7일 이내 되돌리기 23건은 이전 상태로 집계된다는 안내 문구가 항상 붙어 있다(무지개다리 수치에 이 건이 반영되어 있음을 알리는 고지).

### 4. 처리할 일 바로가기

1. 답변 대기 1:1 문의 카드를 누르면 1:1 문의 관리(P30)로 이동한다.
2. 미처리 신고 카드를 누르면 신고·모더레이션(P32)으로 이동한다.
3. 검증 만료 장묘업체 카드를 누르면 제휴 업체 관리(P33)로 이동한다.
4. 법령 점검 예정 행정 안내 카드를 누르면 콘텐츠 관리(P31)로 이동한다.
5. 네 카드의 건수(7·5·1·2)는 기간 세그먼트와 무관하게 항상 같은 값으로 고정된 시안 더미 데이터다.

### 5. 결제 현황 필터·선택·페이지네이션

1. 결제 상태 필터(전체/완료/실패/환불·해지)를 누르면 해당 필터가 활성 표시되고, 결제 내역 표는 조건에 맞는 행만 보이도록 즉시 필터링된다.
2. 결제 내역의 행(바로가기 버튼 제외 영역)을 누르면 해당 행이 선택 표시되고, 다시 누르면 선택이 해제된다. 다른 행을 누르면 이전 선택은 자동 해제된다.
3. "회원 보기" 버튼을 누르면 회원·반려견 관리(P29)로 이동한다.
4. 페이지네이션(이전·1·2·3·다음)을 누르면 눌린 페이지가 활성 표시되고 "N페이지 결제 내역을 불러왔어요" 토스트가 뜬다. 실제 표 내용은 페이지가 바뀌어도 갱신되지 않는다(시안 한정).

## 상태·예외

| 상황 | 화면 처리 |
|------|-----------|
| 기간 변경 후에도 값이 그대로인 항목 | 등록 반려견 누적 수·상태별 반려견 수·결제 내역 표는 고정 더미 값 |
| 새로고침 클릭 | 갱신 시각만 바뀌고 지표 재계산 없음 |
| CSV 내보내기 클릭 | 실제 다운로드 없이 완료 토스트만 표시 |
| 페이지네이션 클릭 | 활성 페이지 표시만 바뀌고 표 내용은 그대로 |

## 확정 필요

- 통계(F44, ADM-05)는 계약서 기능 리스트에 우선순위가 표기되어 있지 않다(다른 기능은 P0/P1 표기). 고객사에 이 기능의 우선순위(필수/선택) 확정을 요청해야 한다.
- 새로고침·CSV·페이지네이션이 시안에서는 실제 데이터 재조회 없이 화면 표기만 바뀌는데, 개발 반영 시 실서버 재조회·CSV 실파일 생성·서버 페이지네이션 연동 범위를 확정해야 한다.
