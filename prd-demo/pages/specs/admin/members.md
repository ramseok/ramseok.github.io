# P29 회원·반려견 관리

> URL `/admin/members` · 대상 **관리자** · 관련 기능 F39, F37

운영 매니저가 가입한 회원과 그 회원이 등록한 반려견을 검색·조회하고, 필요 시 회원 탈퇴를 처리하는 화면이다. 목록에서 회원명·이메일로 검색하거나 반려견 상태·회원 상태로 좁혀볼 수 있고, 행의 "상세" 버튼으로 회원 정보와 등록 반려견을 모두 확인한 뒤 그 자리에서 탈퇴까지 이어서 처리한다. 연락처·동물등록번호 등 개인정보는 목록·상세보기 모두 마스킹 표시된다.

## 동작 정의

### 1. 목록 조회·검색·필터 (F39)

1. 화면 진입 시 더미 회원 15명이 가입일 최신순(내림차순)으로 표시되고, 상단 결과 건수는 "전체 15명"으로 나온다. 첫 행은 박*준(2026.08.30 가입)이며, 가장 오래된 김*연(2024.03.11 가입)은 2페이지 마지막 행에 표시된다.
2. 검색창에 회원명 또는 이메일 일부를 입력하면 즉시(입력 이벤트) 목록이 좁혀지고, 결과 건수 문구가 "검색 결과 N명"으로 바뀐다.
3. 반려견 상태 셀렉트에서 함께하는 중/이별 준비/무지개다리를 고르면 해당 상태의 반려견을 1마리 이상 가진 회원만 남는다.
4. 회원 상태 세그먼트(전체/활성/탈퇴)를 누르면 해당 세그먼트만 활성화되고 목록이 그 상태로 필터링된다.
5. 검색어·필터 중 하나라도 기본값이 아니면 결과 건수 문구가 "검색 결과 N명"으로, 모두 기본값이면 "전체 N명"으로 표시된다.
6. 조건에 맞는 회원이 없으면 테이블에 "조건에 맞는 회원이 없어요." 빈 상태 행이 표시된다.
7. 필터가 바뀌면 현재 페이지가 1페이지로 초기화된다.
8. 목록은 페이지당 8건씩 페이지네이션되며, 이전/다음/숫자 버튼으로 페이지를 이동한다.

### 2. 목록 표시 규칙 (F39, F37)

1. 회원 이름은 "김*연"처럼 가운데 글자가 마스킹된 형태로, 이메일은 "bor***@example.com"처럼 앞부분만 노출되고 나머지는 "***"로 마스킹돼 표시된다.
2. 연락처는 "010-****-1021"처럼 가운데 4자리가 마스킹된 채, 회원명 아래 줄에 이메일과 함께 "이메일 · 연락처" 형태로 작게 표시된다.
3. 반려견 칸에는 회원별로 등록된 모든 반려견이 이름이 적힌 배지로 나열되며, 배지의 아이콘·색이 상태(함께하는 중 해 아이콘/이별 준비 노을 아이콘/무지개다리 구름 아이콘)를 나타낸다.
4. 등록번호 칸에는 첫 번째 반려견의 마스킹된 번호(예: "4100*******8901")만 보이고, 반려견이 2마리 이상이면 "외 N" 문구가 덧붙는다. 등록번호가 없는 반려견은 "미등록"으로 표시된다(예: 김*연 회원의 콩이).
5. 구독 플랜은 "프리미엄"이면 강조 태그, "무료"이면 일반 태그로 표시된다.
6. 가입일 칸은 가입일 아래 줄에 가입 경로(카카오·네이버 등)가, 최근 로그인 칸은 날짜 아래 줄에 시각이 2줄로 표시된다.
7. 행 끝 관리 버튼은 아이콘 없이 텍스트만 있는 "상세"(보조 버튼)와 "탈퇴"(위험 버튼) 2개다.
8. 회원 상태가 "탈퇴"이면 행 전체가 반투명 처리되고, 상태 칸에 "탈퇴" 배지가 표시되며 해당 행의 탈퇴 버튼은 비활성화된다.

### 3. 회원 상세 조회 (F39, F37)

1. 행의 "상세" 버튼을 누르면 상세 모달이 열리고, 상단에 가입일·가입 경로·회원 상태 문구가 표시된다.
2. 회원명·이메일·연락처·구독 플랜·최근 로그인·회원 상태가 2열 표로 표시되며, 이메일·연락처는 목록과 동일하게 마스킹된 값 그대로 노출된다.
3. 등록된 반려견 카드가 이름·견종·나이(무지개다리인 경우 "이별일 YYYY.MM.DD")·마스킹된 등록번호·상태 배지 형태로 나열된다.
4. 이미 탈퇴한 회원의 상세를 열면 "회원 탈퇴 처리" 버튼이 비활성화된다.
5. "닫기" 버튼 또는 모달 바깥 영역을 클릭하면 모달이 닫힌다.

### 4. 회원 탈퇴 처리 (F39)

1. 목록 행의 "탈퇴" 버튼 또는 상세 모달의 "회원 탈퇴 처리" 버튼을 누르면 탈퇴 확인 모달이 뜬다(상세에서 누르면 상세 모달은 먼저 닫힌다).
2. 확인 모달에는 "OOO 님(이메일)을 탈퇴 처리할까요?" 문구와 "탈퇴 처리하면 기록과 추모관이 모두 삭제되고 되돌릴 수 없다. 필요하면 회원에게 먼저 데이터 내보내기를 안내해 달라"는 경고가 함께 표시된다.
3. "취소"를 누르면 아무 변화 없이 모달만 닫힌다.
4. "탈퇴 처리"를 누르면 해당 회원 상태가 즉시 "탈퇴"로 바뀌고, 목록이 현재 필터 기준으로 다시 그려지며, "OOO 님의 탈퇴가 처리됐어요" 토스트가 뜬다.
5. 탈퇴 처리 후에는 해당 행이 반투명 처리되고 탈퇴 버튼이 비활성화된다.
6. 시안에서는 탈퇴 상태가 브라우저 메모리에만 반영되며, 새로고침하면 초기 더미 데이터(황*라만 탈퇴)로 되돌아간다(시안 한정).

| 이미 탈퇴한 회원 | 행 반투명 처리 + 탈퇴 버튼 비활성화 + 상세 모달의 탈퇴 버튼도 비활성화 |

| 페이지 새로고침 | 검색어·필터·탈퇴 처리 결과 모두 초기화(시안 한정, 로컬 저장 없음) |

## 확정 필요

- 탈퇴 처리 시 실제 데이터 처리 정책 — 시안 안내 문구는 "기록과 추모관이 모두 삭제되고 되돌릴 수 없다"(즉시 삭제)로 되어 있으나, 계약서(01_FEAT.md F39)에는 탈퇴 처리 항목만 있고 삭제 범위·유예기간·법정 보관 의무 데이터 처리 방식은 미기재 — 고객사 확인 필요
- 회원 상세·탈퇴 처리에서 다루는 개인정보(이메일·연락처·동물등록번호) 원문 조회 권한 — 시안은 항상 마스킹만 보여주며 관리자가 원문을 볼 수 있는 별도 절차(권한자 인증 등)가 있는지 확인 필요
