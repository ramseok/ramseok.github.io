PROJECT 01

PRD Toolkit

계약서 → 기획서 · 화면 시안 자동 생성
이 장의 화면에 대하여

실제 고객사 프로젝트의 기획서는 비밀유지 대상이라 첨부할 수 없습니다. 이어지는 산출물은 모두 가상의 예시 프로젝트 「무지개 일기(가칭)」를 파이프라인에 넣어 생성한 결과물입니다. 도구의 동작과 결과물 형태를 보여주기 위한 것이며, 특정 고객사의 내용이 아닙니다. 전체 산출물은 ramseok.github.io/prd-demo 에서 직접 열어볼 수 있습니다. 화면 확인용으로 정적 HTML만 공개한 것이라 실제 서버 배포와 DB 연동은 되어 있지 않습니다.

문제
  • Figma로 화면을 한 장씩 그려 초안까지 1~2주
  • 1명이 여러 프로젝트를 병렬로 맡는 구조라 기획에 일정 · 공수가 몰려 전체 일정의 병목 발생
  • 기획서 · 디자인 가이드 · 고객 피드백 · 테스트케이스가 서로 다른 문서로 파편화
  • 피드백이 어느 화면 · 어느 항목 얘기인지 매번 다시 대조
해결

계약서 PDF를 출발점으로 기능 정의 → 페이지 맵 → HTML 시안 → 화면별 기획서 · 테스트케이스까지 한 번에 생성

  • 동작하는 HTML 시안 — 버튼 클릭 · 페이지 이동이 실제로 되는 화면
  • 리뷰 레이어 — Ctrl + / 로 화면별 기획서 · 고객 코멘트 · 테스트케이스를 한 패널에
  • 디자인 · 컴포넌트 가이드 — DESIGN.md 토큰으로 전 화면 통일
  • 품질 게이트 — 생성과 검토를 분리, 내용 기준으로 완료 판정
  • 링크 전달 — 자동 배포 후 링크 하나로 공유, 피드백은 DB에 기록
성과
  • 파편화된 문서 4종 → 링크 1개 — 기획 · 디자인 · 피드백 · 테스트를 한 곳에서 진행
  • 고객사 만족도 상승 — 직접 버튼을 누르고 페이지를 이동하며 기획서와 함께 검토
  • HTML · CSS 인계 — 개발팀이 실제 마크업 위에서 바로 착수
  • 초안 작성 1~2주 → 30분~1시간 — 최초 산출물 기준

아래는 위 흐름의 04~05단계 산출물입니다. 가상의 프로젝트라 실제 서버 배포와 DB 연동은 되어 있지 않아 로그인 · 저장 같은 기능은 동작하지 않고, 코멘트 · 테스트케이스 결과는 보고 있는 브라우저에만 임시로 남습니다. 시안 화면에서 Ctrl + / 를 누르면 그 화면의 기획서가 열립니다.
